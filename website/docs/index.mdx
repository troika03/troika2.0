# Troika

Troika is a voice-first personal AI assistant for Android and Windows. Voice is
the primary interface; chat is an optional way to enter text and inspect
details.

> Tell Troika what needs to be done. It understands the task, selects the
> required capabilities, completes the work, saves the result, and remembers
> useful context for next time.

## Who Troika 1.0 is for

| Audience | Need | Example scenario |
|---|---|---|
| Students | Handle assignments and files | Explain an assignment, research it, create DOCX/PPTX, and remember the deadline. |
| Early-career professionals | Reduce document and research busywork | Prepare a report, comparison, file, research summary, and next actions. |
| Developers and power users | Delegate technical work | Request research, file work, or a coding task without choosing an internal agent topology. |
| Everyday users | Avoid complex AI interfaces | Say “remind me”, “find this”, “open it”, or “make a document”. |

## Product status

Troika 1.0 is under active development. Only capabilities that pass the
canonical launch-plan gates are presented as product features. Experimental
runtime capabilities remain preserved behind developer controls and are not
part of normal UI or marketing.

## About these docs

This site currently documents the inherited open-source runtime for Troika
contributors. Some deeper pages still use upstream compatibility names while
the safe native rebrand proceeds. They are developer documentation, not the
Troika sales site. The consumer website, pricing, account, support, status and
legal pages are separate launch-plan work.
