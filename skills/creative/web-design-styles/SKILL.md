# Design стили для gemini_code (сайты + презентации)

## Правило №1: НЕ AI-look

Дефолтный кодер (Gemini/Claude без правил) генерирует «AI-эстетику»: фиолетово-розовые градиенты, glassy карточки в 3 колонки, эмодзи 🚀⚡ на кнопках, «FAST / SECURE / RELIABLE» в три колонки, gradient text в hero. Плюс — клипарт, стикеры Telegram-стайл, cartoon-avatars (dicebear и т.п.). Это узнаётся сразу и выглядит дёшево.

**Правила анти-AI уже зашиты в `_HEADLESS_RULES` обёртки `gemini_code`**. Тебе не нужно их пересказывать. Но **обязательно** передавай `design_style` — иначе кодер выберет сам и промахнётся.

## Голос → design_style

| Услышал | design_style | Когда применять |
|---|---|---|
| «портфолио», «студия», «дизайнер», «фотограф», «архитектор», «строго», «минимализм», «редакция» | `swiss` | Профессионалы, креативщики, B2B консалтинг. Дефолт когда сомневаешься. |
| «брутализм», «брутальный», «дерзкий», «яркий», «весёлый», «по-молодёжному», «инди» | `brutalist` | Стартапы, инди-проекты, contenttech, креатив-агентства. |
| «лендинг саас», «продукт», «дашборд», «приложение», «современно», «технологично» | `modern_minimal` | SaaS, productivity, tools, mobile-first. |
| «уютный», «тёплый», «эко», «бренд», «семейный», «handcraft», «кафе», «бутик» | `scandinavian_warm` | Кафе, лайфстайл, бренды, ремесло, eco. |
| «для разработчиков», «devtool», «API», «терминал», «тёмная тема», «hacker» | `tech_dev` | DevOps, API SaaS, CLI tools, AI tools для разработчиков. |

Если ни одно не подходит — `swiss`. Он никогда не выглядит как AI.

## Голос → output_kind

| Услышал | output_kind | Что кодер сделает |
|---|---|---|
| «сайт», «лендинг», «портфолио», «дашборд», «приложение», «страничка» | `web` (default) | HTML/CSS/JS или React проект в workspace, preview + ZIP на телефон. |
| «презентация», «слайды», «питч-дек», «pptx», «повер-поинт», «презенташка», «для выступления» | `presentation_pptx` | Реальный `.pptx` файл через python-pptx: 16:9, свои фигуры для декора, реальные фото из интернета в assets/, deck.pptx в корне. |

**Пример вызова для презентации:**
```
gemini_code(task="Питч-дек для стартапа X, 10 слайдов: проблема, решение, рынок, команда, финансы",
            design_style="modern_minimal",
            output_kind="presentation_pptx",
            extra_constraints="палитра как у Notion")
```

Файл `deck.pptx` появится в workspace, ZIP уедет Мише в Downloads. Открывать в PowerPoint / Keynote / LibreOffice Impress.

## Медиа: реальные фото ИЛИ своя SVG — не стикеры

Правила уже зашиты в HEADLESS. Коротко:

- **Реальные фото/видео** — качаются из интернета через `fetch` MCP или `requests`. Живые источники: **Openverse** (`api.openverse.engineering/v1/images/?q=...`, без ключа, CC), **Wikimedia Commons** (`commons.wikimedia.org/w/api.php`, без ключа), **Pexels/Unsplash Official** (если есть ключ `PEXELS_API_KEY`/`UNSPLASH_ACCESS_KEY` в env). ⚠️ `source.unsplash.com` **закрыт** — не использовать. Кладутся в `assets/img/*.jpg`.
- **Своя графика inline SVG** — рисует кодер сам: hero-графика, декор, разделители, иконки, брендовые знаки. Геометричные линии, 1.5-2px stroke, `currentColor`.
- **ЗАПРЕЩЕНО**: эмодзи на кнопках, стикеры, cartoon-avatars, клипарт, picsum/placeholder, «фото довольных сотрудников с хэндшейком».

В `.pptx` то же самое: реальные фото — через `slide.shapes.add_picture(local_path)`, декор — через `slide.shapes.add_shape` (прямоугольники/эллипсы/линии/стрелки), а не clip-art из шаблонов PowerPoint.

## Дополнительные параметры

`extra_constraints` — свободный текст в prompt кодеру:
- цветовая палитра («зелёно-кремовый», «корпоративный синий»)
- референс («как у Linear», «в духе Apple», «как Notion»)
- что **НЕ** хотим («без анимаций», «без тёмной темы»)
- для .pptx: количество слайдов, фирменный шрифт, логотип

## Примеры

**«Сделай мне лендинг для кофейни»**
→ `gemini_code(task="Лендинг кофейни Mocha в Москве: меню, адрес, часы, фото интерьера", design_style="scandinavian_warm", extra_constraints="палитра — тёплый беж и тёмно-зелёный, скачай 3-4 реальных фото интерьера/кофе с Openverse (api.openverse.engineering)")`

**«Хочу портфолио, я фотограф»**
→ `gemini_code(task="Портфолио фотографа Миши Иванова, 12 проектов сеткой", design_style="swiss", extra_constraints="максимум фокус на фото; hero-графика — тонкая SVG-линия, не фото")`

**«Сделай питч-дек для инвесторов, я делаю AI-ассистента»**
→ `gemini_code(task="Питч-дек для AI-ассистента 'Тройка': проблема, продукт, MRR прогноз, команда, ask $500K", design_style="tech_dev", output_kind="presentation_pptx", extra_constraints="12 слайдов, шрифт JetBrains Mono для чисел, палитра тёмный navy + amber")`

**«Слайды для лекции про Возрождение»**
→ `gemini_code(task="Слайды-лекция 'Флорентийское Возрождение', 15 слайдов с картинами и датировками", design_style="swiss", output_kind="presentation_pptx", extra_constraints="скачай реальные изображения картин с Wikimedia Commons, крупно на полстраницы")`

**«Сделай дашборд для управления заказами»**
→ `gemini_code(task="Дашборд для управления заказами интернет-магазина", design_style="modern_minimal", extra_constraints="как Linear")`

## Что НЕ делать

- НЕ говори кодеру «сделай красиво» без указания стиля — промахнётся в AI-эстетику
- НЕ проси «современный дизайн» — слишком расплывчато
- НЕ комбинируй стили («брутализм + glassy») — получится мешанина
- НЕ передавай эмодзи в task как декор («сделай сайт 🚀 крутого стартапа ✨») — эмодзи попадут в контент
- Для .pptx НЕ забывай `output_kind="presentation_pptx"` — иначе кодер сделает HTML-слайды

## Что говорить Мише голосом

После того как кодер закончил, не отдавай ZIP молча. Скажи коротко:
- «Готов лендинг в швейцарском стиле, отправила тебе. Открой preview, если что не так — скажи»
- «Сделала портфолио, минимализм, как просил. Хочешь что-то изменить?»
- «Дек 12 слайдов готов, deck.pptx у тебя в Downloads. Открывай в PowerPoint»
