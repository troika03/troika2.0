# Web-дизайн стили для gemini_code

## Правило №1: НЕ AI-look

Дефолтный Gemini генерирует «AI-эстетику»: фиолетово-розовые градиенты, glassy карточки в 3 колонки, эмодзи на кнопках, «FAST / SECURE / RELIABLE» в три колонки, gradient text в hero. Это узнаётся сразу и выглядит дёшево.

**Правила анти-AI уже зашиты в `_HEADLESS_RULES` обёртки gemini_code**. Тебе не нужно их пересказывать. Но **обязательно** передавай `design_style` параметром — иначе Gemini выберет сам, и может промахнуться.

## Голос → стиль

| Услышал | design_style | Когда применять |
|---|---|---|
| «портфолио», «студия», «дизайнер», «фотограф», «архитектор», «строго», «минимализм» | `swiss` | Профессионалы, креативщики, B2B консалтинг. Дефолт когда сомневаешься. |
| «брутализм», «брутальный», «дерзкий», «яркий», «весёлый», «по-молодёжному», «инди» | `brutalist` | Стартапы, инди-проекты, contenttech, креатив-агентства. |
| «лендинг саас», «продукт», «дашборд», «приложение», «современно», «технологично» | `modern_minimal` | SaaS, productivity, tools, mobile-first. |
| «уютный», «тёплый», «эко», «бренд», «семейный», «handcraft», «кафе», «бутик» | «scandinavian_warm» | Кафе, лайфстайл, бренды, ремесло, eco. |
| «для разработчиков», «devtool», «API», «терминал», «тёмная тема», «hacker» | `tech_dev` | DevOps, API SaaS, CLI tools, AI tools для разработчиков. |

Если ни одно не подходит — `swiss`. Он никогда не выглядит как AI.

## Дополнительные параметры

Можешь передать в Gemini подсказку через `extra_constraints`:
- цветовая палитра («хочу зелёно-кремовый», «корпоративный синий»)
- референс («как у Linear», «в духе Apple», «как Notion»)
- что **НЕ** хотим («без анимаций», «без тёмной темы», «без эмодзи»)

## Примеры

**«Сделай мне лендинг для кофейни»**
→ `gemini_code(task="Лендинг кофейни Mocha в Москве: меню, адрес, часы, фото интерьера", design_style="scandinavian_warm", extra_constraints="палитра — тёплый беж и тёмно-зелёный")`

**«Хочу портфолио, я фотограф»**
→ `gemini_code(task="Портфолио фотографа Миши Иванова, 12 проектов сеткой", design_style="swiss", extra_constraints="максимум фокус на фото, минимум UI")`

**«Сделай дашборд для управления заказами»**
→ `gemini_code(task="Дашборд для управления заказами интернет-магазина", design_style="modern_minimal", extra_constraints="как Linear")`

**«Сделай страничку про мой Open Source проект»**
→ `gemini_code(task="Landing для CLI-утилиты", design_style="tech_dev")`

## Что не делать

- НЕ говори Gemini «сделай красиво» без указания стиля — он промахнётся в AI-эстетику
- НЕ просите «современный дизайн» — слишком расплывчато
- НЕ комбинируй стили («брутализм + glassy») — получится мешанина

## Что говорить Мише голосом

После того как Gemini закончил, не показывай ему ZIP молча. Скажи коротко:
- «Готов лендинг в швейцарском стиле, отправила тебе. Открой preview, если хочешь поменять стиль или вернуть нам по-другому — скажи»
- «Сделала портфолио, минимализм, как просил. Хочешь что-то изменить?»
