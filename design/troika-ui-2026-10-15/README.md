# Тройка: макеты всех страниц

Концепт интерфейса Android и Windows от 15 октября 2026 года.

В комплекте 144 экрана: 36 страниц Android и 35 страниц ПК с компактным
окном, каждая в тёмной и светлой теме. Дополнительно подготовлены восемь
векторных состояний голосового интерфейса. Это макеты для обсуждения;
установленные приложения и сервер не изменены.

Откройте `index.html` для просмотра всех страниц с фильтрами. В папке
`prototype` находятся интерактивные версии с янтарной анимацией из Android.
Нажатие на микрофон показывает демонстрацию прослушивания без записи звука.

## Редактирование в Figma

[Открыть созданный файл Figma](https://www.figma.com/design/zJ6BhvNM0UrHURsWOh3PmK?node-id=5-216).
На 16 октября перенесены 134 экрана: все 72 Android и 62 экрана ПК.
Надписи являются обычными Text-слоями, значки и контур голоса — векторами.
Цвета связаны с переменными Тройки, типографика — со стилями Golos Text.
Часть повторяемых блоков представлена компонентами с текстовыми свойствами.

Перенос последних десяти светлых экранов ПК и восьми отдельных голосовых
состояний остановлен лимитом Figma MCP на Starter. Они сохранены в комплекте;
готовый локальный импортёр остатка — `figma/finish-import/code.js`.
Порядок добавления в тот же файл указан в `FIGMA.md`.

Быстрый вариант: перетащите один из четырёх файлов из `boards` на холст
Figma. В `svg` находятся отдельные экраны. Геометрия, цвета и контуры
редактируются как векторы. Figma может преобразовать SVG-текст в кривые.

Для обычных редактируемых текстовых слоёв используйте `figma/code.js`.
Этот локальный импортёр создаёт страницы и фреймы через Figma Plugin API,
а текст — через `createText`. Инструкция находится в `FIGMA.md`.

## Файлы и ограничения

- `boards`: четыре общих SVG-полотна для Figma.
- `svg`: отдельные векторные экраны.
- `components`: состояния голосового интерфейса.
- `figma`: локальный импортёр и исходные данные слоёв.
- `previews`: PNG для проверки оформления.
- `prototype`: интерактивный просмотр телефона и ПК.
- `source`: исходные фрагменты интерфейса.
- `fonts`: неизменённый Golos Text и лицензия SIL OFL.
- `manifest.json`: перечень страниц, размеры и результаты проверки.

SVG и Figma-компоненты содержат статичные кадры. Непрерывная деформация
контура и дыхание свечения работают в интерактивных версиях. Снижение
движения в системных настройках учитывается. Для прототипирования
переходов в Figma можно использовать отдельные компоненты состояний;
связи и Smart Animate автоматически не добавляются.

Исходные логотипы, шрифт и палитра взяты из `brand/troika`. Формула,
амплитуда и длительности янтарного контура перенесены из Android
`StatusOrb`. Примеры задач, документов и остатка демонстрационные.
Оплата, восстановление доступа и незавершённые функции не объявляются
готовыми на основании этого комплекта.

Все экраны отрисованы в браузере. Проверены XML SVG, наличие текста
и векторных слоёв, ссылки на файлы и локальная работа импортёра с моделью
Figma API. Настоящий импорт выполнен частично; файл открыт в редакторе.
Главная Android просмотрена после исправления размеров кнопок. Проверка
всех готовых страниц в Figma ещё не завершена из-за лимита подключения.
Подробные результаты находятся в `quality-report.json`.
