# Как открыть макеты в Figma

## Созданный файл

[Открыть Тройку в Figma](https://www.figma.com/design/zJ6BhvNM0UrHURsWOh3PmK?node-id=5-216).
Файл открыт в редакторе. На 16 октября добавлены 134 из 144 экранов:
72 Android и 62 ПК. Обе темы Android перенесены полностью; у ПК не добавлены
последние десять светлых экранов. Отдельная страница голосовых состояний
подготовлена, но восемь компонентов ещё не перенесены. Причина — лимит
Figma MCP на бесплатном плане, подтверждённый редактором.

Надписи редактируются как текст, поверхности и иконки — как отдельные
слои. Повторяемые блоки имеют главные компоненты справа от экранов;
их текст меняется в свойствах экземпляров. Цвета и текстовые стили
можно менять через Variables и Styles. В узкой панели холст показан
без боковых панелей: `Ctrl+\` возвращает интерфейс Figma, `Shift+2`
приближает выбранный экран. Для работы удобнее открыть ссылку в полном окне.

Точный список перенесённых фреймов и остатка — `figma/live-import-state.json`.

## Добавить оставшиеся макеты без подключения MCP

Готовый `figma/finish-import/code.js` добавляет только недостающие десять
экранов ПК и восемь голосовых компонентов в существующие страницы этого
файла. Он не использует сеть, не удаляет и не меняет готовые экраны.
Повторный запуск пропускает уже добавленные макеты с теми же названиями.

1. В настольной Figma откройте созданный файл по ссылке выше.
2. В `Plugins → Development → New plugin` создайте локальный плагин
   для Figma Design без интерфейса и сохраните его папку.
3. Замените его `code.js` готовым файлом `figma/finish-import/code.js`.
   Сохраните выданный Figma `manifest.json` и его ID.
4. Запустите плагин из `Plugins → Development`.

Этот дополнительный локальный запуск ещё не проверен в настольной Figma.
Весь остаток также готов для продолжения переноса после восстановления
доступного лимита подключения. Повторно импортировать все экраны не нужно.

## Быстро: векторные экраны

1. Создайте пустой Figma Design-файл.
2. Перетащите на холст нужный файл из `boards`, например `android-dark.svg`.
3. Разгруппируйте импорт, чтобы выбирать отдельные экраны и элементы.

Для одного экрана используйте файл из `svg/android` или `svg/desktop`.
SVG импортируется как редактируемая векторная геометрия. Текст при этом
может стать кривыми. Если нужно менять надписи как обычный текст,
используйте следующий вариант.

## Обычный текст и отдельные фреймы

Этот способ требует настольной Figma. Компиляция и установка библиотек
не нужны: готовый `code.js` уже находится в комплекте.

Полный импортёр создаёт отдельную страницу для каждой платформы и темы.
На Starter выбирайте одну платформу и тему в новом файле, чтобы не превысить
лимит страниц. Для уже созданного файла используйте импортёр остатка выше.

1. В настольной Figma создайте пустой Design-файл.
2. Откройте `Plugins → Development → New plugin`.
3. Выберите `Figma design`, назовите импортёр «Макеты Тройки», выберите
   `Custom UI` и сохраните папку локального плагина.
4. Замените созданный в этой папке `code.js` файлом `figma/code.js`
   из комплекта. Исходный `manifest.json` сохраните: его ID выдаёт Figma.
   Поле `main` должно оставаться равным `code.js`, а `documentAccess` —
   `dynamic-page`. Никакая сеть импортёру не нужна.
5. В меню `Plugins → Development` запустите «Макеты Тройки».
6. Выберите платформу и тему, нажмите «Добавить макеты».

Импортёр добавляет новые страницы и не очищает существующие.
Повторный запуск создаёт ещё один набор страниц. Надписи создаются
как Text-слои, поверхности — как прямоугольники, иконки и логотипы —
как векторы. Голосовые состояния создаются отдельными компонентами.

Если Figma сообщает об отсутствии Golos Text, установите
`fonts/GolosText-Variable.ttf`, перезапустите Figma и повторите импорт.
Лицензия шрифта находится рядом. При наличии Golos Text в редакторе
установка не требуется.

Анимация доступна в `prototype/android.html` и `prototype/desktop.html`.
В Figma импортируются статичные редактируемые состояния. Автоматические
связи прототипа не создаются. Старый полный локальный импортёр оставляет
абсолютное расположение; подключённый перенос и импортёр остатка используют
Auto Layout для простых рядов кнопок и полей, сохраняя геометрию макетов.

## Источники

Поведение SVG и создание локального плагина описаны в официальных
руководствах [импорта графики](https://help.figma.com/hc/en-us/articles/360040028034-Add-images-and-videos-to-designs)
и [быстрого запуска плагина](https://developers.figma.com/docs/plugins/plugin-quickstart-guide/).
Нативный текст создаётся через [createText](https://developers.figma.com/docs/plugins/api/properties/figma-createtext/).

Комплект проверен локально; реальный импорт выполнен частично, как указано выше.
