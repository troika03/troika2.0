# Тройка: новый дизайн голосового ассистента

Макеты от 20 октября 2026 года. Последние уточнения владельца: новый современный
интерфейс без привязки к прежней композиции или палитре; ChatGPT и Codex служат
ориентирами простоты; кнопки и поле ввода могут быть полупрозрачными. Текущая
версия использует графит и мятный акцент. Ранний янтарный вариант этого дня
заменён этим направлением.

## Просмотр

- `index.html` — все страницы с выбором платформы, темы и раздела.
- `first-five.html` — первые пять страниц: главная, разговор, дела, файлы, разработка.
- `prototype.html` — кликабельная версия с голосовым контуром и переходами.
- `previews/` — 266 изображений: 66 страниц Android и 67 страниц ПК в двух темах.
- `svg/` — те же 266 кадров как векторы с текстом.
- `review/all-*.jpg` — общие полотна для проверки комплекта.
- `PAGE_COVERAGE.csv` — полный состав 67 логических страниц и состояний.
- `Troika-Figma-editable.zip` — исходники импортёра, сцены и шрифт.
- `FIGMA.md` — как получить редактируемые слои в Figma и фактический статус переноса.

Длинные страницы прокручиваются внутри рабочей области. На Android заголовок
остаётся на месте, поле ввода разговора закреплено снизу. В SVG и данных для
Figma сохранены также слои за границей прокрутки: их можно редактировать.

## Визуальная система

| Назначение | Тёмная тема | Светлая тема |
|---|---|---|
| Фон | `#202322` | `#FAFCF9` |
| Навигация | `#181B1A` | `#F0F3EE` |
| Поверхность | `#2C302E` | `#EDF2EC` |
| Основной текст | `#F4F7F4` | `#1F2923` |
| Вторичный текст | `#A4ADA6` | `#68756B` |
| Разделитель | `#3A413D` | `#DDE5DB` |
| Акцент | `#A7E4BF` | `#286747` |

Шрифт — Golos Text, локальный оригинал с лицензией OFL. Основной текст
разговора — 16/26–27, обычный интерфейс — 14/22, подписи — 12/18.
Иконки и логотип взяты из оригинальных ресурсов Тройки; интерфейсные иконки
используют цвет текущего текста. Голосовой контур использует `#8DE0B4`.
Сферы, изображения вместо интерфейса и декоративные градиенты панелей не используются.

Прозрачные кнопки имеют заливку около 4,5% белого в тёмной теме; поле ввода —
5,5% светлого мятного. Размытие 12–20 px применяется к поверхности, не к тексту.
Контраст текста не снижается вместе с заливкой. Для уменьшенной прозрачности
используется непрозрачная поверхность; для уменьшенного движения анимация выключена.

На Android основные разделы открываются из выдвижного меню. Голос — главное
действие главной и отдельного голосового экрана, текст доступен снизу. На ПК
навигация постоянно слева, разговор ограничен удобной шириной. Рабочая область
разработки следует компоновке Codex: отдельная колонка проектов и задач,
разговор в центре, diff кода и переключаемые файлы/предпросмотр справа.
Обычная навигация ассистента в этой среде заменяется навигацией проектов.
Поля команды, ветка, ресурс и пауза доступны в пределах рабочего окна.

## Границы макета

Все сообщения, документы, имена проектов, расход, результаты тестов и даты —
демонстрационные. Прототип не вызывает микрофон, API, оплату, настоящую регистрацию,
отправку в поддержку или удаление данных. Цифры успешных проверок показывают
форму представления результата, а не проверку текущего продукта.

Ревью моделью, фактический запуск тестов и визуальный просмотр показаны отдельно.
Финальная отправка файлов и локальные проверки требуют понятного подтверждения.
Оплата и почтовое подтверждение не объявлены готовыми.

Приложения Android и WPF в этой задаче не изменялись. Перенос в них описан в
`../../docs/development/UI_IMPLEMENTATION_GUIDE.md` и выполняется отдельным этапом.

## Воспроизведение

Используются установленный Python, Playwright с Edge и Pillow. Новые зависимости
для продуктового runtime не добавляются.

```text
node tools/build_assets.cjs
python tools/render.py --all
python tools/check_prototype.py
python tools/check_exports.py
node tools/check_importer.cjs
python tools/package_design.py
```

Проверки сохранены в `review/`. Они подтверждают локальную компоновку, переходы и
структуру экспорта. Проверка импортёра с моделью API не заменяет запуск в Figma.

Ориентиры композиции: [ChatGPT](https://chatgpt.com/) и
[официальная презентация Codex](https://openai.com/index/introducing-the-codex-app/).
Фирменные знаки OpenAI в продуктовые макеты не переносятся.
