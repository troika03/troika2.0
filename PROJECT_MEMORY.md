## Пробный контракт действий на устройстве — 12 ноября 2026

В тестовом API есть выключенный по умолчанию dry run. Согласие привязано к
активному Run, выбранному устройству Android или Windows и токенам обеих сторон.
Срок до двух минут, осмотр до 15 секунд, до восьми операций. Повтор команды
возвращает прежний статус. Stop, отзыв и завершение Run закрывают доступ.
Осмотр синтетического окна приходит отдельно от технического статуса и не
попадает в SSE Run или базу. Все результаты помечены `simulated`.

Отдельный Run с `computer_dry_run: true` ждёт согласия и передаёт Hermes
один тестовый инструмент. Целевое устройство может получить запрос по своему
токену. Модель видит квитанцию и признак доступности нажатия. Описание окна
остаётся в контроллере, тестовый диалог не сохраняется. Итог симуляции
формируется по квитанциям. Политики, API и реальный цикл Hermes с подставной
моделью проверены в 471 тесте. Один тест пропущен. Общий набор Windows ранее
завершился с ошибками. Окно Windows `--computer-use-consent` получает запросы
на loopback и отправляет подтверждение, отказ и Stop по токену тестового
устройства. Полный набор WPF прошёл, локальный API подтвердил получение
запроса, согласие и Stop из нативного окна.
[Протокол и границы](docs/audit/TROIKA_COMPUTER_DRY_RUN_2026_11_11.md).

## Тестовый редактор Windows из Run — 12 ноября 2026

Отдельный режим `computer_windows_lab` на loopback передаёт команды
Hermes в нативный тестовый редактор. Допуск привязан к Run и токену
выбранного Windows-устройства. Модель выбирает осмотр, ввод одной строки
из задачи и сохранение. Устройство проверяет байты временного файла. Старый
клиент использует встроенную пробную строку. Квитанции, SSE, история и
дампы запросов не содержат текст команды. Локальный Stop и
истечение команды проверены нативно. Серверный Stop блокирует дальнейшую
выдачу и отчёты. Сквозной прогон Hermes с подставной моделью сверил байты
файла со строкой из команды, включая кириллицу и эмодзи.
В тестовой сборке есть отдельный `TroikaComputerUseEditor.exe`. UI Automation
из процесса `TroikaDesktop.exe` проверяет образ редактора, HWND, PID и
идентификатор окна. Стандартный `ValuePattern.SetValue` принимает только
точный текст действующего одноразового допуска. Парольные поля блокируются
до чтения значения. Сохранение выполняет кнопка редактора. Нативные тесты
подтвердили отказ при подмене, истечении команды и Stop. Полный WPF и
32 проверки Computer Use прошли, включая повторный Run в отдельном редакторе.
Сторонние приложения, живой OpenRouter и Android остаются
отдельными этапами.
[Настройка и проверки](docs/audit/TROIKA_WINDOWS_RUN_EDITOR_2026_11_12.md).

## Визуальный осмотр Windows — 12 ноября 2026

Тестовый режим `--window-preview` получает один кадр отдельного пробного
процесса через Windows Graphics Capture. Согласие открывает осмотр до
двух минут. Снимок ограничен выбранным окном и 1280 × 800 пикселями.
Проверка с перекрывающим окном подтвердила границу по пикселям.
Окно с запретом захвата отклоняется. Windows OCR читает русский текст
кадра. Кадр и результат остаются на ПК, предпросмотр очищается через
15 секунд, при скрытии окна и при Stop. Сохранён отдельный режим
`--preview` для отрисовки пробного поля WPF. Отдельный режим `--vision-lab` после
просмотра и отдельного подтверждения передаёт один кадр на тестовый
сервер 127.0.0.1. Сервер убирает метаданные PNG и формирует один
мультимодальный запрос через SDK Hermes с подставным ответом в памяти.
Отдельный Run `computer_windows_vision` на 127.0.0.1 получает проверенный
PNG от назначенного Windows-устройства. Windows показывает OpenRouter
как получателя, требует отдельного подтверждения и пропускает локальный
OCR в этом режиме. Hermes передаёт один кадр и текст запроса явно
указанной модели OpenRouter. В ответе Run приходит описание. Требуются
ключ и модель, переключение на другой провайдер отсутствует. Stop,
срок кадра и отзыв устройства закрывают передачу. Кадр не попадает
в историю, SSE, дампы запросов и хуки плагинов. Подставной ответ доступен
только в явно включённом режиме проверок.
Живой Run с Gemma 4 26B через OpenRouter определил синий фон пробного
окна. Сборка WPF и 109 целевых проверок прошли.
[Запуск и проверки](docs/audit/TROIKA_WINDOWS_RUN_EDITOR_2026_11_12.md#кадр-в-тестовом-run-hermes).

## Единый Run Windows с осмотром и действиями — 12 ноября 2026

## Модельный пилот Windows — 12 ноября 2026

Опциональный запуск `--computer-use-agent` подключает тестовый редактор к
отдельному серверу на `127.0.0.1`. Сервер выбирает команду через модельный клиент
Hermes и явно указанную модель OpenRouter. Запрос содержит задачу, технический
статус и признаки доступных действий. До разрешения владельца запросов нет.
Локальный Stop отклоняет команды, полученные после отмены. Сохранение проверяется
чтением файла. Локальная модель и production не используются.
Нативные вызовы пилота выполняются из отдельных процессов Windows. Каждый
процесс проверяет PID, дескриптор и идентификатор тестового редактора.
Разрешение и проверка записи остаются в процессе окна.
Полный набор WPF и проверка сборки `winexe` прошли. Ранее прошли 15 целевых
тестов Python и сквозная проба HTTP с подставным SDK. Живой запрос OpenRouter
и работа со сторонними приложениями пока не проверены.
[Протокол пилота](docs/audit/TROIKA_WINDOWS_COMPUTER_MODEL_PILOT_2026_11_12.md).
