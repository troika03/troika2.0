## Назначение
Troika — голосовой AI-ассистент для Android и Windows: задача на естественном языке → помощь с поиском, документом или повседневным делом → понятный результат. Текст — запасной вариант. Продвигаем **реальные сценарии**, а не абстрактный «самый умный ИИ».
