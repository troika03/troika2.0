# Место у окна

Вертикальная история о Тройке по визуальному референсу из TikTok. Рома принимает сообщение одноклассницы за приглашение на свидание. Тройка обращает его внимание на вложение и реакцию под сообщением. Переписка, план рассадки и имена придуманы для ролика.

На первом кадре видны сообщение Леры, сердечко и вопрос «Это свидание?». Камера переходит с переписки на план класса, возвращается к реакции и открывает имя её автора на реплике «Вы». В финале Тройка советует взять линейку.

| Время | Действие |
|---|---|
| 0–5,5 с | Сообщение с сердечком, вопрос героя и переход к разговору с Тройкой. |
| 5,5–13,6 с | Камера выделяет две фразы Леры и вложение. |
| 13,6–19,7 с | Раскрывается план рассадки на контрольной по геометрии. |
| 19,7–27,7 с | Крупный план реакции и открытие её автора. |
| 27,7–33,4 с | В разговоре появляется ответ про линейку и цветы. |
| 33,4–36 с | Фирменный знак и приглашение в Telegram. |

Главный экран и знак взяты из проекта Тройки. Экраны переписки и документа нарисованы для сцены. Озвучка диалога создана двумя русскими голосами серии через Fish Audio. Финальная фраза взята из ранее записанной озвучки Brio. Музыка и звуки подготовлены для этого монтажа.

## Сборка

В папке ролика выполнить `python prepare.py`, затем `python render.py`. Нужны Python с NumPy, SciPy, Playwright и Pillow, Chrome и FFmpeg. Все использованные реплики находятся в `audio/`. Для проверки отдельных кадров запустить `python render.py --preview`. Локальный результат — «Тройка — Место у окна.mp4», 1080 × 1920, 30 кадров/с, H.264 и стерео AAC.
