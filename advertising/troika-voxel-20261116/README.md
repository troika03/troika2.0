# Тройка. Пять минут до созвона

Вертикальная 3D-версия рекламы. 32,8 секунды, 1080 × 1920, 30 кадров/с, H.264. Диалог целиком в субтитрах. В MP4 одна видеодорожка.

| Время | Кадр |
|---|---|
| 00:00–00:05,04 | Встречные крупные планы. Герой торопится, Тройка шутит про оставшееся время. |
| 00:05,04–00:10,35 | Команда фонарика. Камера опускается к телефону и флешке. |
| 00:10,35–00:17,58 | Вопрос о записи экрана. На сцене появляются экран Тройки и название официального источника. |
| 00:17,58–00:23,45 | Просьба о трёх слайдах и демонстрационная карточка PPTX. |
| 00:23,45–00:29,31 | Просьба выступить за героя. Пауза, реплика Тройки и подмигивание. |
| 00:29,31–00:32,80 | Камера отъезжает. Оба персонажа, знак Тройки и платформы. |

Приёмы из приложенного `Download.mp4` — кубические персонажи, тёмная сцена с терминалом, встречные крупные планы, субтитры над персонажами и общий план после шутки. Модели, анимация, сцена и реплики сделаны для Тройки. Профиль @sevanklav был недоступен в веб-просмотре. [@sevanklav](https://www.tiktok.com/@sevanklav)

На телефоне и ноутбуке показаны тестовые рендеры действующего дизайна из `design/troika-ui-2026-11-13/`. Сочетание для записи экрана сверено по документации Microsoft. Результаты и время ответа показаны для примера. Лицензия шрифта Golos Text находится в `public/OFL.txt`. [Справка Microsoft](https://support.microsoft.com/en-us/windows/apps/use-snipping-tool-to-capture-screenshots)

## Пересборка

В локальном ZIP лежат проект, фирменные изображения и шрифт. Нужны Node.js, Python с Playwright, FFmpeg, Edge или Chrome с поддержкой WebGL2.

```sh
npm ci
python render.py
```

Выход — `final/Troika-Five-Minutes-3D.mp4`. `python render.py --preview` выводит адрес локального плеера. Для контроля подходят `--stills --scale 0.5` и `--frames 714-983 --scale 0.5 --output work/ending.mp4`.

Реплики и моменты смены планов хранятся в `src/beats.ts`, модели — в `src/models.ts`, свет и движение — в `src/stage.ts`. `src/troika.tsx` собирает сцену и субтитры в Remotion.
