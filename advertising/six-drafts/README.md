# Шесть раз стёр

Вертикальный диалог для Тройки. Герой никак не решается ответить девушке, пока Тройка не напоминает, что он сам сказал вчера. Переписка с девушкой остаётся за кадром. Её сообщение цитирует герой, его ответ звучит поверх уходящего экрана Тройки.

Монтаж длится 24 секунды. В кадре главный экран и чат на нативных Android-виджетах с постановочными данными. Визуальный ориентир — наклон телефона на чёрном фоне, приближения к фразам и короткая заставка из предоставленного референса. В монтаже оригинальные реплики, музыка и эффекты.

| Время | Действие |
|---|---|
| 0–8,5 с | Микрофон, первая фраза героя, переход в чат |
| 8,5–11,4 с | Камера поворачивается к вопросу Тройки |
| 11,4–14 с | Мятный пузырь с признанием, музыка стихает |
| 14–17 с | Тройка отвечает «Ей это скажи, не тупи» |
| 17–20 с | Герой печатает ответ девушке. Щелчок отправки |
| 20–24 с | Фирменный знак и надпись «Ссылка в шапке профиля» |

## Сборка

Из папки `hermes-android` выполнить `flutter test --no-pub "<путь к этой папке>/capture_test.dart"`, задав `TROIKA_AD_ROOT` абсолютным путём к этой папке. Тест открывает домашний экран и чат, подставляет четыре сценарных сообщения и сохраняет слои в `local/screens`. Счёт, микрофон и сеть для съёмки не нужны.

Сохранить присланную озвучку из Google AI Studio (Gemini 3.8 Flash TTS, Brio и Nika, 20,28 с) в `local/gemini-dialogue.wav`. Из папки ролика выполнить `python prepare.py`, `python mix.py` и `python render.py`. Нужны Pillow, NumPy, SciPy, Playwright, Chrome и FFmpeg. Паузы и темп оригинальной записи сохранены.

`python render.py --preview` собирает лист кадров. Шкала GSAP в `index.html` ищется по времени для каждого кадра. Портретный рендер пишет 720 кадров в H.264, добавляет AAC stereo и сохраняет `Шесть раз стёр — Gemini.mp4` рядом со сценой. Бинарные материалы хранятся локально.
