# Что умеет Тройка

Второй вертикальный ролик серии. Первый кадр ставит героя за пять минут до доклада. Он спрашивает, где слайды. Через 1,2 секунды в списке файлов появляется выделенная презентация «Как устроен звук.pptx», затем Тройка рассказывает об остальных возможностях. Видеомонтаж длится 84 секунды и включает полные субтитры, музыку и строку «Ссылка в шапке профиля».

Переписка, история, источники, формы документов, список команд и вкладки каталога сняты с Flutter-виджетов на демонстрационных данных. Для памяти, списка файлов, дел, напоминаний и запроса разрешения использованы экраны из комплекта дизайна от 20 октября. Вход в Windows показан через компактное окно из комплекта от 13 ноября.

## Сборка

1. Из `hermes-android` запустить `flutter test --no-pub <полный путь к capture_test.dart>`. В `TROIKA_OV_SCREENS` передать абсолютный путь к `local/screens` этой папки.
2. В папке ролика выполнить `python prepare.py`, затем `python render.py`. Нужны Playwright с Chrome, FFmpeg, Pillow, NumPy и SciPy. Общий рендерер и часть локальных дизайн-ресурсов берутся из первого ролика `../six-drafts`.
3. Монтаж сохраняется в `Что умеет Тройка — До доклада 5 минут.mp4`. Команда `python render.py --preview` собирает лист кадров.

Реплики из Google AI Studio сохранены в `Brio.txt` и `Nika.txt`. В диалоге Gemini 3.8 Flash TTS сначала звучит вопрос Brio, затем весь ответ Nika. Монтажная копия содержит музыку и экранный текст. Для сведения нужен скачанный из AI Studio диалог.
