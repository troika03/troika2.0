# Шестое обновление

Постановочный ролик в тёмной теме Android-клиента Тройки. В кадре один телефон. Камера поднимается к островку, когда говорит разработчик, и спускается к голосовому знаку, когда отвечает Тройка. В финальной паузе стихает волна, затем камера возвращается к голосовому экрану.

| Сцена | Механика OBSION |
| --- | --- |
| Запуск и первый подъём к островку | №538 · Линза ныряет в героя Screen Studio, держится на плашке релиза. Плавный наезд на телефон и короткое удержание масштаба. |
| Первый ответ и оправдание | №11 · Агент решает чат о возврате, затем выбор номера телефона. Фразы входят целиком и оседают снизу. |
| Спор | №101 · Переписка прокручивается, световой скан превращает отправленный пузырь в шифр. Камера продолжает движение, новый текст принимает акцент. |
| Пауза, ответ Тройки и последняя реплика | №620 · Phantom на телефоне, наезд на Coinbase, скриншот карточки PnL. Камера показывает оба элемента, приближается к голосовому знаку на шутке и возвращается к островку. |

Интерфейс восстановлен по рендеру `design/troika-ui-2026-11-13/android-dark-390.png`, а островок по `HermesOverlay.kt`. Цвета, шрифт Golos Text и фирменный знак из рабочего продукта. Реплики и перемещение камеры размечены отдельно для двух предоставленных дублей. Звук включает короткие синтезированные щелчки и тихую подложку с паузой перед шуткой.

## Сборка

`python render.py --voice TAKE1.mp3 --voice TAKE2.mp3` собирает два файла H.264/AAC в папке проекта. Нужны Python с Playwright, NumPy и Pillow, Chrome и FFmpeg. GSAP загружается один раз в `local/`; в этой папке также остаются данные формы волны и контрольные кадры. Ключ `--preview` строит лист кадров первого дубля. Исходная речь и готовое видео хранятся локально.
