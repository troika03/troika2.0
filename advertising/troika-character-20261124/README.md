# Когда твой ИИ уже охренел

Вертикальный ролик Тройки с постановочным диалогом ElevenLabs. Макос играет разработчика, Маруся — Тройку. В кадре компьютер, телефон и островок голосового управления. Монтаж воспроизводит согласованный сценарий и заканчивается адресом Telegram.

Компьютер в первой сцене уже включён. При работе на ПК видны подтверждение сеанса, плашка управления и указатель. Телефон возобновляет выбранный трек.

## Сборка

Скачать записи ролей ElevenLabs в `local/dev.mp3`, `local/troika.mp3` и отдельную новую реплику в `local/hook.mp3`. Разметить границы реплик в секундах в `local/segments.json`. Для получения слов с таймкодами можно запустить `python audio.py --transcribe`. Команда `python audio.py` собирает стереодорожку и точные тайминги, `python render.py --voice local/voice-master.wav` — готовый ролик. Добавить `--preview` для проверки кадров.

Речь, локальные таймкоды и экспорт остаются на устройстве. Для сборки нужны Python, FFmpeg, FFprobe и Chrome с Playwright.
