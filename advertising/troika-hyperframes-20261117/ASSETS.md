# Источники материалов

Видео используют визуальный язык Тройки и новые сценарии. Ни кадры, ни речь из роликов референса в монтаж не включены.

| Материал | Источник и применение |
|---|---|
| Референс монтажа | [CORTEX / @sevanklav](https://www.tiktok.com/@sevanklav). Разобраны 9 доступных публикаций по десяти кадрам каждого ролика: тёмный фон, наклонённый телефон, приближение интерфейса, диалог, короткая развязка. Это разбор кадров; полный слуховой анализ всей ленты не проводился. |
| Android и Windows | Макеты Тройки из `design/troika-ui-2026-11-13/`. Главные экраны показаны изображениями, остальные действия — постановочные примеры в том же оформлении. |
| Значок | Утверждённый значок из `design/app-icon-20261115/icon-512-rounded.png`. |
| Шрифт | Golos Text, локальный файл проекта. Лицензия OFL приложена рядом со шрифтом. |
| Музыка | [Rising Forest — Diego Nava, Mixkit](https://mixkit.co/free-stock-music/edm/), [Stock Music Free License](https://mixkit.co/license/modal/musicFree/). Использован фрагмент имеющегося исходника проекта; музыка приглушена под речь. Лицензия проверена 17 ноября 2026 года. |
| Голоса | Новые реплики через OpenRouter / Fish Audio S2.1 Pro Free. Рассказчик — [«Энергичный рассказчик»](https://fish.audio/m/48ec28a45588422b977a86460c11977f/), Тройка — [Alina / Fish Official](https://fish.audio/m/cde09f575c314ecaa801614c94a738af/). По уточнению владельца заменены оба тембра. Образцы голоса автора не использовались. |
| Подача | Быстрая, разговорная. Финальные реплики синтезированы без драматических тегов; темп дополнительно увеличен на 10% у мужчины и на 8% у Тройки без изменения высоты голоса. |
| Инструкция Windows | Сочетание Win + Shift + R и порядок записи проверены по [справке Microsoft](https://support.microsoft.com/ru-ru/windows/apps/use-snipping-tool-to-capture-screenshots). В примере показана Windows 11. |
| Анимация | HyperFrames 0.9.59 и GSAP 3.15.0. Изучены компоненты реестра `ui-focus-zoom` и `yt-camera-move`; сцены созданы под эти истории и оформление Тройки. |

Исходные ролики референса, прежние неудачные дубли речи и ключи сервисов не входят в готовый комплект. Бинарные материалы и итоговые видео хранятся локально, вне Git.
