# Тройка: три короткие истории

Три оригинальных ролика с энергичными голосами рассказчика и Тройки, музыкой и субтитрами. Рассказчик — «Энергичный рассказчик», Тройка — Alina. Вертикальный формат 1080 × 1920, 30 кадров/с, H.264/AAC. Оформление взято из материалов Тройки. Постановочные диалоги и результаты отмечены в кадре.

| Ролик | Файл в `final/` | Длительность |
|---|---|---:|
| Кофе за твой счёт | `Troika-Coffee.mp4` | 20,37 с |
| Шеф написал одно слово | `Troika-Shorter.mp4` | 20,50 с |
| Уже восемь вкладок | `Troika-Tabs.mp4` | 21,37 с |

`Troika-HyperFrames-Editable.zip` содержит три самостоятельных проекта со всеми изображениями, шрифтами и звуком. Внутри открыть папку `coffee`, `shorter` или `tabs` в HyperFrames Studio. Текст, расположение объектов, движение, озвучка и музыка доступны для изменения. Речь уже встроена: для обычного монтажа ключи сервисов не нужны. Отдельные SRT лежат рядом с видео и внутри соответствующего проекта; в MP4 субтитры уже вписаны в изображение.

В рабочем каталоге главный проект — история про кофе; остальные находятся в `episodes/shorter` и `episodes/tabs`. Порядок сцен и текст — в `episodes.json`, точные тайминги — в `timelines.json`, визуальная раскадровка — в `STORYBOARD.md`.

## Повторная сборка

Проекты закреплены на HyperFrames 0.9.59. В Codex использовать официальный launcher из установленного навыка HyperFrames. Для самостоятельного запуска через Node.js:

```powershell
npm run dev
npm run check
npm run render
```

`build.py` восстанавливает сцены из сценариев внутри checkout Тройки, используя локальные исходники продукта. `voice.py` создаёт новые реплики при наличии настроенного ключа OpenRouter и доступности выбранной бесплатной модели. `verify.py` проверяет все проекты и снимает контрольные кадры; `render.py` экспортирует MP4 и проверяет декодирование, число кадров и громкость. Готовый ZIP уже содержит собранные проекты и не требует запуска этих Python-скриптов.

## Проверка и ограничения

Все три проекта прошли HyperFrames check. Проверены кадры сцен, стыки, уменьшенные изображения для телефона и кадры, извлечённые из конечных MP4. Пройдено полное декодирование файлов; параметры и измерения звука находятся в `final/verification.json`.

Текст новой речи проверен распознаванием. Звук измерен, но не прослушан агентом. Окончательный выбор звучания остаётся за владельцем; пример нового тембра показан в чате. Бинарные файлы хранятся локально, вне Git. Ролики никуда не опубликованы.
