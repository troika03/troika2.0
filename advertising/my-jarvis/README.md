# Я создал своего Джарвиса

Вертикальный ролик о Тройке. Автор показывает голосовую команду на семь вечера, Тройка подтверждает её, и в списке появляется напоминание на 19:00. Вторая половина показывает поиск с источником, форму документа и приглашение в Telegram на бета-тест.

Экраны Android взяты из съёмки «Что умеет Тройка». Экран напоминаний использует продуктовый макет с демонстрационными данными. Визуальный план и приёмы камеры записаны в `design/DESIGN.md`.

## Сборка

Из этой папки запустить `python build.py`. Нужны Python, Playwright с Chrome, Pillow и FFmpeg. Рендерер серии покадрово экспортирует HTML и GSAP в 1080 × 1920 при 30 кадрах/с. Музыка и 18 субтитров входят в монтажную копию. Для проверки десяти выбранных кадров запустить `python build.py --preview`.

Голоса Gemini Speech — Brio у автора и Nika у Тройки. Для сведения с исходной записью запустить `python build.py --voice local/gemini.wav --starts local/starts.json`. Файл starts содержит время начала каждой строки из story.json в секундах, измеренное по конкретной записи. Экспорт с голосом сохраняется отдельным MP4.
