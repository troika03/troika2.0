# Тройка. Выключить духовку

Вертикальный ролик на 18 секунд. Формат 1080 × 1920, 30 кадров/с, H.264 и AAC.
Финальный файл сохраняется в `final/Troika-Duhovka.mp4`.

| Время | Сцена |
|---|---|
| 00:00–00:03,20 | Янтарный контур нагрева, отметка 180° и тиканье. |
| 00:03,20–00:08,80 | Голосовые дуги Тройки реагируют на просьбу. Фраза появляется синхронно с речью. |
| 00:08,80–00:14,10 | Главный экран Android. Через монтажный скачок на десять минут приходит напоминание. |
| 00:14,10–00:18,00 | Фирменный знак, название и платформы. |

Главный экран — тестовый рендер клиента от 13 ноября из
`design/troika-ui-2026-11-13/android-dark-390.png`. Дуги, фон, подписи и
типографика сверены по `StatusOrb`, `HomeScreen` и `TroikaColors` в рабочем
checkout. Просьба и напоминание образуют постановочную сцену. Карточка
напоминания нарисована для ролика, а время ответа задано монтажом.

Логотип и Golos Text взяты из приложения и комплекта бренда. Лицензия шрифта
находится в `public/OFL.txt`. Голосовые фрагменты взяты из дорожек `wake.mp3`
и `remind.mp3` ролика `advertising/release-20261115`. Музыка, тиканье и
звуки переходов синтезируются в `sound.py`.

## Пересборка

Нужны Node.js, Python с NumPy, Pillow и Playwright, FFmpeg, Edge или Chrome.
`TROIKA_BROWSER` задаёт путь к другому Chromium.

В локальном ZIP материалы уже на местах. В checkout выполните
`python prepare.py --voice-dir <папка голосовых дорожек>`.
Опция `--screen` позволяет указать исходный рендер Android, если он
хранится отдельно от checkout.

```sh
npm ci
python sound.py
python render.py --preview
python render.py
```

Команда с `--preview` печатает адрес локального плеера. Без этого флага
Remotion Player передаёт кадры на кодирование в FFmpeg. Поддерживаются
`--frames 78-300`, `--scale 0.5`, `--stills` и `--output`.
Сцены и их время редактируются в `src/troika.tsx`, звук — в `sound.py`.
