## Рабочие инструкции и архитектура

- [Запуск закрытой beta](TROIKA_CLOSED_BETA_SETUP.md): product mode, аккаунты, токены, локальные проверки.
- [Политика подписки](TROIKA_SUBSCRIPTION_ECONOMICS.md): согласованные 12 октября тарифы Free/Plus/Pro, расчётные токены, состав функций, экономика и порядок перехода; production cost engine ещё не включён.
- [Production](TROIKA_PRODUCTION_SERVER.md): ОС, сеть, единственный deployment path и незакрытые инфраструктурные требования.
- [Синхронизация аккаунта](ACCOUNT_SYNC_ARCHITECTURE.md): реализованный серверный account scope и будущая офлайн-очередь.
- [Память пользователя](TROIKA_USER_MEMORY.md): owner-scoped API и ограничения.
- [Уведомления](TROIKA_NOTIFICATION_PREFERENCES.md): opt-in, quiet hours и API настроек.
- [Хранение и удаление данных](DATA_RETENTION_AND_DELETION_POLICY.md): локальный retention и ещё не реализованный backup lifecycle.
- [Одноразовый экран](SCREEN_SNAPSHOT_THREAT_MODEL.md): review закрытого beta snapshot; не распространяется на live vision.
- [Миграция имён](TROIKA_NATIVE_REBRAND_MIGRATION.md): совместимость установленного Android и Python runtime.
- [Справочник runtime](development/RUNTIME_GUIDE.md): технические правила для Python, gateway, plugins и TUI.
- [Python проверки](audit/PYTHON_FAILURES.md): неуспешные файлы и результаты полного доступного набора.

## Исторические материалы

[Архив](archive/README.md) сохраняет старые решения и доказательства для сравнения.
Старые планы монетизации, Offline Beta, PC, Kali и улучшений больше не задают
scope, цены или порядок работ. Их прежние пути ведут на пояснение и архив.
Аудиты [раздела 3](TROIKA_1_0_SECTION_3_AUDIT.md) и
[раздела 6](TROIKA_1_0_SECTION_6_AUDIT.md) относятся к указанным датам;
свежие результаты находятся только в аудите функций.

`hermes-kanban-v1-spec.pdf` — справочный материал унаследованного Kanban,
не план или обязательство релиза Troika 1.0.

`website/` — унаследованная документация Hermes для разработчиков;
`troika-site/` — незавершённый сайт продаж Troika. Эти каталоги имеют разные задачи.
