## Подтверждённый сценарий

записаны в 09:12:33. Последовательность:

1. `troika_tool_search(capability=phone)` — успех.
2. `troika_tool_call(tool=android_open_app)` — `app_not_found`, 10,06 с.
3. `troika_tool_search(capability=screen)` — `capability_unavailable`, 0,02 с.
4. Текстовый ответ модели; вызова `troika_device_control` не было.

`phone` предоставляет базовые команды. `screen` относится к отдельному
режиму снимка экрана, который в production выключен.
Для чтения элементов, нажатий, ввода и прокрутки существует `control`.
Его серверный флаг и настройка пользователя включены; файл инструмента
присутствует в текущем образе. Модель в проверенном запросе выбрала другие
возможности. Отказ `screen` не доказывает недоступность `control`.

Телефон подключался к каналу в 09:10:45 и 09:11:41 и вернул прикладную ошибку
в 09:12:32. Связь в момент команды работала. Почему имя приложения не
найдено, по этим данным не установлено. В текущем `findPackage` используется
package name и совпадение с label; комментарий об алиасах не соответствует
реализации. Установленную APK и список приложений по USB проверить нельзя:
подключённых устройств нет.
