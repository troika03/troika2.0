# Проверка автопилота разработки, 14 октября 2026 года

Реализован ограниченный фоновый автопилот для Pro. У проекта отдельный Run,
session, Stop и команда API-specialists. До четырёх проектов занимают четыре
из пяти слотов аккаунта; разговор может использовать пятый. План, дизайн,
запись исходников, независимое ревью и исправления выполняются через API.
Уход со вкладки не отменяет работу. Голосовые отчёты ждут свободного разговора,
называют проект и поддерживают отключение. DOCX/PPTX собираются доверенными
renderer из типизированного содержания. Это проверка исходников и сборок,
не production deployment и не E2E установленного приложения. Последующее
[серверное обновление 15 октября](AUTOPILOT_SERVER_2026_10_15.md) проверено отдельно.

## Живой пример бесплатного API

Тройка создала сайт вымышленной студии интерьеров «Север» без изображения
образца. Проект содержит HTML, CSS, JavaScript, настоящие тесты валидации,
README, требования, план, DESIGN.md и MODEL_REVIEW.md: девять файлов плюс
manifest упаковки. Исходники примера вручную не исправлялись. Ошибки Node
и браузера передавались самой модели следующей задачей с действующими файлами.

Использовались проверенные по официальному каталогу OpenRouter free-модели
nvidia/nemotron-3-super-120b-a12b:free и dots-studio/dots-3-note-preview:free.
Последнее исправление двух файлов выполнено первой моделью за пять API-вызовов;
независимое ревью прочитало текущую версию и вернуло passed. Модельный отчёт
сохраняет execution=not_run и visual_review=not_checked: локальные проверки
ниже выполнял разработчик, они не выдаются за самостоятельный Visual verifier.

В настоящем браузере фильтр «Гостиная» оставил две карточки. Форма после
синтетических данных показала: заявка сохранена только на устройстве, внешней
отправки нет. Доступное имя кнопки соответствует сохранению. На ширине 304 px
после модельного исправления header заканчивается около 167 px, заголовок
начинается около 275 px; горизонтального переполнения нет. Временная viewport
настройка сброшена. Снимки и ZIP сохранены в локальном work, без пользовательских
данных в Git.

Это работающий прототип с простым оформлением и условными иллюстрациями.
Пример не доказывает дизайн уровня исходного референса или качество всех
сайтов, приложений и презентаций. Автоматический изолированный preview и
Visual verifier ещё не подключены.

## Ограничения

- До 40 файлов, 160 KB контекста, 64 вызовов и 15 минут на один проект;
  одновременно максимум три specialists и два free-запроса на процесс.
- Только проверенный zero-price endpoint/model. Платного fallback нет.
  Корпоративные вызовы списывают месячные prompt + completion; личный API
  допустим только с проверенной конкретной free-моделью, без возврата к ключу Тройки.
- При занятых слотах отказ 429; постоянной очереди нет. Бюджет/остаток проходят
  действующий ledger; продолжение через согласование в карточке пока отсутствует.
- Исполнение сгенерированного кода на облачном сервере запрещено. Локальные
  тесты требуют отдельного действия и прежних разрешений. Model review и
  статический detector копирования функций не доказывают полноту тестов.
- Исходники и Run находятся в RAM, передача файла имеет TTL 600 секунд.
  Durable resume/checkpoints, пауза и уточнение текущего Run не реализованы.
- Наблюдение и голос работают при открытом приложении. Голос/push при полностью
  закрытом приложении и свежий физический E2E остаются незавершёнными.
