# Troika 0.1: основная APK и состояние задержки — 27 октября 2026

Основная Тройка уже обновлена и отвечает. Владелец сообщает задержку и через
кнопку микрофона, и через фоновое пробуждение. Стабильное начало содержательного
голосового ответа через 1–2 секунды после конца реплики пока не подтверждено.
Последнее уточнение владельца: в фоне голос появляется примерно через 3–4 секунды
после плашки. Единица — секунды. Это субъективная оценка без timing trace;
отсчёт от плашки не равен отсчёту от конца речи.

## Постоянная операционная команда API

На сервере сохраняются закрепляющие образ override-файлы. Для последующего
обслуживания этого API использовать исходные project directory, env file и compose
вместе с `activation-pinned-image.override.yaml`:

```sh
docker compose \
  --project-name production \
  --project-directory /srv/troika/current/deploy/production \
  --env-file /srv/troika/current/deploy/production/resource-images.env \
  -f /srv/troika/current/deploy/production/compose.yaml \
  -f /srv/troika/releases/voice-latency-20261027/activation-pinned-image.override.yaml \
  up -d --no-deps --no-build --pull never --timeout 60 api
```

Базовый compose без закрепляющего override может вернуть старый tag API.
Для отката сохранены прежний образ и
`/srv/troika/releases/voice-latency-20261027/rollback-pinned-image.override.yaml`:
в той же API-only команде заменить только последний `-f` на этот файл. Не удалять
оба override и прежний образ; после операции проверять образ, hashes исходников,
health и сохранность окружения. Значения секретных env-файлов в отчёт не включены.
