# Серверный автопилот разработки: 15 октября 2026 года

По запросу владельца обновлён действующий API Тройки. Android-клиент установлен
ранее в тот же день. Основной сервер использует `troika-production:autopilot-20261015-api`,
digest `sha256:3c78d14f23804cf8cc1b25208a5185aaf4a3eb8bdc29bbb73ef5f71d22a25b89`.
STT и SearXNG не заменялись. Сохранены compact context, месячный ресурс,
личный API, существующие данные, tokens, consents и операторские beta-периоды.
Оплата, почта и остальные отключённые возможности не включались.

## Выпуск

Восемь Python-модулей commit 24e945f объединены с действующим compact runtime
через трёхстороннее слияние от 018acf7. Конфликтов нет. Незавершённый код
напоминаний, клиентов и сайта из общей рабочей копии не включён.
Образ построен дополнительным слоем поверх проверенного production image;
зависимости не переустанавливались. Сначала проверен отдельный экземпляр
с изолированной БД; затем изменён только API image tag прежнего Compose.

Перед переключением активных ресурсных Run не было. Config и image tags
сохранены в защищённом activation-backup; сделаны согласованные копии SQLite
(6 БД). Рабочий volume сохранён. Автоматический откат при
неуспешном health возвращает предыдущий образ, не восстанавливая старые данные.

Использованные бесплатные модели: nvidia/nemotron-3-super-120b-a12b:free.

действующим месячным ledger; личный API сохраняет отдельную политику.

## Ограничения и откат

API health после переключения healthy. Публичный development endpoint теперь
существует; без авторизации возвращает 401. SHA-256 всех восьми модулей
совпал с проверенным overlay; отдельный тестовый контейнер удалён.
Серверный выпуск не подтверждает
воспроизведение отчёта, микрофон, навигацию или сохранение ZIP на Samsung.
Полный installed-client E2E Android и установка WPF остаются открытыми.
Модель выполнила ревью исходников; сгенерированные unittest не запускались.
Автоматический visual reviewer, durable resume и голос при полностью закрытом
клиенте не добавлены. Прежние ограничения RAM/TTL и бюджетов сохраняются.

Для отката сохранить текущие данные, вернуть предыдущий `TROIKA_IMAGE_TAG`
из `/srv/troika/releases/autopilot-20261015/activation-backup/resource-images.env`
и пересоздать только API прежним Compose с `--no-build --no-deps api`.
Предыдущий образ: `troika-production:compact-20261014-api`.
Config в этом выпуске не менялся; старые SQLite поверх действующих не возвращать.

Локальные агрегаты, подготовка и ZIP примера находятся в
`work/server-autopilot-20261015`; они не включены в Git.
