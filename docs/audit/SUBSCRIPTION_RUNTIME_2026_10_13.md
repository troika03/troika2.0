# Месячный ресурс и личный API: проверка 14 октября 2026 года

Владелец разрешил закончить работу без подключения оплаты. Последнее уточнение:
через ключ Тройки даже бесплатная модель расходует ресурс; через личный ключ
пользователя вызовы модели не списывают токены подписки.

## Реализовано и включено

Production использует `troika-production:resource-context-20261014-api` и
`resource-personal-20261014-stt` через прежний `deploy/production/compose.yaml`.
Месячный счётчик включён; дневной guard подписки заменён. Технический rate limit
сохраняется. API и STT читают один операторский config. Оплата и SMTP выключены.

Бесплатная модель через ключ Тройки списывает `prompt_tokens + completion_tokens`:
весь переданный input, включая память, историю, инструменты и cached input,
плюс ответ. Reasoning повторно не добавляется. Стоимость провайдера может быть
нулевой; это не основание обнулять расход ресурса сервиса. Платные модели
используют опубликованные расчётные коэффициенты. Перед вызовом резервируется
верхняя оценка, после подтверждения расхода лишний резерв возвращается.

Некоторые модели Free передают несовместимую разбивку reasoning/completion.
При подтверждённом нулевом счёте сохраняются оба исходных счётчика, а сумма
для диагностики помечается верхней оценкой. Списание следует верхним полям
prompt/completion, а не повторному сложению reasoning. Для платных моделей
несовместимые счётчики по-прежнему останавливают продолжение.

Личный OpenRouter/OpenAI подключается в Android и WPF. Сервер принимает ключ
только для текущего запроса в RAM, выбирает фиксированный HTTPS endpoint,
заменяет ключ и модель основного и вспомогательных SDK и запрещает переход на
ключ Тройки. Account permissions и task slots сохраняются. Платный голос
сервиса учитывается отдельно. Android сохраняет только режим, провайдера,
модель и owner; ключ находится в RAM. После перезапуска требуется повторный
ввод; foreground/native voice не переходят молча на ключ Тройки. Windows
хранит личный ключ через DPAPI CurrentUser отдельно для каждого аккаунта.

Два существующих активных Pro получили по 10 млн токенов на один тестовый
календарный месяц, до 14 ноября 2026 года. Это операторская beta-выдача:
платежи, receipts и payment intents не создавались. По окончании периода
доступ возвращается на Free. Для Free/Welcome осталось 13 333 333 токена
месячного фонда; вместе с 20 млн beta-токенов это не превышает первоначальный
предел 1 000 ₽ по коэффициенту. Старые данные, токены и остатки не сбрасывались.

Whole-Run квоты, concurrency 1/1/3, heartbeat, approval бюджета, bounded vision,
каноническая проверка ЮKassa и полных возвратов, SMTP/HMAC verification, Welcome
с beta/paid gate, account export/delete реализованы. Billing и письма остаются
выключенными по решению владельца. Неподдержанные платные маршруты блокируются.

auxiliary, стабильность system prompt и продуктовая личность. Последующие
изменения затрагивают только документы; runtime source совпадает с этим tree.

Анализ Flutter: **0 errors, 0 warnings, 46 info**. Ruff новых модулей прошёл.

Живой закрытый canary: два обращения через корпоративный Free списали 7 904
токена. Личный режим списал 0; неверный личный ключ отклонён HTTP 409 и не
вызвал fallback. Действительный личный режим испытан с операторским ключом как
приватным fixture; отличающиеся ключи и отсутствие обращения корпоративного
клиента проверены unit-тестами. Ключи не выводились и не сохранялись в отчёт.

Свежая проверка публичного HTTPS после сокращения входа: обычные обращения
списали 6 303 токена, личный режим — 0, неправильный личный ключ отклонён 409,
checkout выключен, временный аккаунт удалён. Дополнительная диагностическая
верхняя оценка 6 720 не стала списанием. До сокращения отдельный smoke дал
6 608 списанных токенов. Эти результаты включают разные ответы Free router и
не доказывают одинаковое уменьшение каждого production bill.

На production начальный набор включает только `troika_tool_search` и
`troika_tool_call`, automatic skill list false, pre_llm_call context hooks 0.
Полные инструкции разработки теперь приходят через discovery, вместо
постоянной личности. Локальный cl100k_base: 3 303 до 2 674 токенов, минус 629,
примерно 19% блока личности/инструкций. Личность, память и история сохранены;
маркер версии 5 обновляет старый cached system prompt на следующем запросе.
[План входного контекста](../development/INPUT_TOKEN_PLAN.md).

Edge TTS/Groq STT, общий баланс двух устройств, возврат резерва, исчерпание

## Ограничения выпуска

До продажи остаются merchant/mail, фискальная настройка и реальные счета,
сверка неизвестного расхода и компенсация сбоев, partial refunds/prorating,
финансовое хранение и pending payment при удалении, public anti-abuse и фонд
от выручки. Каталог фиксируется при первом использовании сервиса, а не целиком
при покупке. Исследования, specialist scheduler и произвольные repository builds
этот commit не объявляет завершёнными. Полный end-to-end голос/напоминания на
телефоне и модель с настоящим внешним пользовательским ключом не проверялись.
