## Реализовано

Сервер хранит owner/device, состояние, версии и хеши. Запрос и исходники
находятся только в RAM с TTL 600 секунд, постоянная копия — на устройстве.
Продолжение проверяет собственника, устройство и digest подтверждённой версии;
idempotency сохраняется в БД без текста запроса. Есть пауза, уточнение, Stop,
дополнительный согласованный бюджет и автоматическое восстановление только
в пределах оставшегося согласованного бюджета. Месячный ресурс не сбрасывается.
Временной предел сохраняет промежуточную копию. Stop имеет приоритет над паузой.

Ревью читает все файлы ограниченными порциями. До 100 файлов/2 MiB и 50 KB
на модельный файл. Несогласованный Office-тип при плане исходного кода
отклоняется. Отсутствующая функция — замечание ко всему проекту без выдуманной
строки; ложная цитата не принимается. Проверки привязаны к задаче, исходникам
и версии кода/среды. Изменение аннулирует подтверждение, подмена копии запрещена.

Checker: фиксированные pytest, Node, React/Vitest, HTML/React и Office render.
Контейнер одноразовый, без сети, non-root, read-only root, cap-drop ALL,
Chromium sandbox, 0,75 CPU/512 MiB/128 процессов/100 секунд и bounded tmpfs.
Основной API не получает Docker socket/shell. Установки зависимостей из проекта
и npm scripts нет. Код, вывод и изображения не попадают в постоянные серверные
stores/журналы. Изображения читает отдельная проверенная бесплатная vision-модель.
Исправления существующего файла могут быть точными заменами: непустой old_text
должен находиться ровно один раз. Неоднозначная замена и no-op отклоняются,
текущий отчёт переопределяет completed-plan. CSS проходит доверенный parser
перед Node/React; ошибки передаются обратно автору, а не маскируются ревью.
Designer документов получает поддерживаемые композиции renderer. Контактный
лист сохраняет реальные границы страниц без добавленных белых полей.
Ревью исходников, исполненные тесты и визуальная проверка отражаются отдельно;
неподдержанный стек не получает passed. Платного fallback нет.

Android: копии вне backup, отдельный foreground service и уведомление,
сохранение результатов и голос при свободном разговоре. Его MethodChannel
отделён от прежнего offline checker. ПК: DPAPI и tray. Старый отчёт предыдущей
попытки после продолжения удаляется. Force-stop Android/явный выход из ПК
прекращают наблюдение. Ошибки доставки не удаляют проверенную локальную копию.

## Дополнительная диагностика 17–18 октября

В обычном UI воспроизведён тайм-аут при мобильной сети/VPN; после отключения
VPN новый проект выполнился за 42 секунды. Это проверка конкретной сети,
а не утверждение о несовместимости со всеми VPN. На устройстве обнаружен
выключенный переключатель голосовых отчётов; он включён по запросу владельца.

Диагностика native observer локализовала IllegalStateException на проверке
папки результата: canonical путь сравнивался с неканоническим dataDir. Теперь
оба пути приводятся к canonical виду; проверка границы папки и owner hash
сохранена. Позднее создание AppLifecycleListener больше не принимает уже
скрытое приложение за foreground. Принятый Run остаётся в pending handoff
до появления в серверном снимке, включая принятие POST после ухода с экрана.
Состояния озвучки содержат только фиксированные коды и хеш-ссылку отчёта;
тексты, ключи, исходники и аудио в эти журналы не включаются.
