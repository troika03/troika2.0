# Компактный контекст Тройки: проверка 14–16 октября 2026

Владелец одобрил сокращение рабочего контекста при сохранении полных
исходных данных. Изменения относятся к product API; Android/WPF в этой
задаче не пересобирались. Оплата и почта остаются выключенными.

## Изменение

В постоянном блоке остаются имя, характер, язык, честность, приватность,
подтверждения и маршрутизация. Подробные инструкции приходят вместе с нужной
capability. Начальный набор модели по-прежнему содержит две схемы. Новый
`troika_context` загружается через существующий plugin API по необходимости;
операторские/default toolsets не расширяются.

Полные SOUL, память, проекты и сообщения сохраняются. SDK получает производную
копию с релевантной памятью, точными выдержками и полными свежими ходами.
При большой завершённой цепочке инструментов хвост сокращается; текущая
реплика пользователя остаётся целиком. С 16 октября большие результаты
инструментов внутри текущего хода также получают обратимые references. Индекс обозначает неполноту и даёт номера оригиналов.
Полный исходный текст читается постранично с проверкой account/device token.
Создание индекса не вызывает модель. RAM-кеш проверяет владельца и весь
префикс, ограничен размером/TTL и очищается при удалении аккаунта.

Учёт резервирует преобразованный запрос. Корпоративный Free сохраняет правило
prompt + completion, включая cache; BYOK за модель не списывает ресурс подписки.
Платные голосовые операции и коэффициенты моделей не изменялись. Флаг
`product_compact_context_enabled` по умолчанию false; прежний режим сохраняется.

## Ограничения

Сокращённое представление не гарантирует одинаковый ответ любой модели.
Для отсутствующей детали нужно чтение оригинала, которое добавляет шаги.
Если нужен весь материал, его передача остаётся расходом. Multimodal/async
history и отключённый reader передаются без индекса. Текущая реплика пользователя не
обрезается. Результаты голоса и файла на установленном Samsung приведены в
дополнении ниже; разработка и платежи этими проверками не закрываются.

### Диагностика и сохранность оригиналов

`usage.diagnostics` содержит накопительные модельные вызовы, число provider
receipts, локальные input components и фактические prompt/completion totals.
Системные инструкции, память, история, schemas, tool results, текущий запрос и
framing оцениваются раздельно. Это локальная оценка отправленного SDK payload,
не фактическая разбивка провайдера. Неизвестные multimodal расходы не выдаются
за ноль; число вызовов без usage позволяет видеть неполноту фактической суммы.
Cache и reasoning не добавляются повторно к основным значениям. В audit идут
три записи `tokens.task`, `tokens.input`, `tokens.provider` с числовыми полями;
сообщения, память, пути файлов, содержимое и ключи не записываются.

Большие tool results заменяются только в производной SDK-копии. Reference
сохраняет ошибки, статусы, sources, receipts и точные значения; десятичные числа
не проходят округление binary float. Неоднозначный JSON и большие evidence
могут остаться полными. Discovery schemas и страницы оригиналов остаются
полными. Поиск даёт смещение совпадения; повторное чтение всего оригинала,
продолжение, account isolation, Stop и revoke проверены. Вызов Stop немедленно
закрывает reader, даже если выполняющийся SDK ещё не вернул управление.
Сериализованные оригиналы истории в живом API совпали с исходными.
Резервируется отправленный payload, а не сохранённый большой оригинал.

Локальный синтетический результат: **16 085 против 314 cl100k_base токенов**,
98,0% сокращения этого результата. Полная задача требует отдельных измерений.

### Качество и полный расход

Изолированные API с отдельными БД и временными аккаунтами проверили имя Тройки,
русский язык, краткий и подробный ответ, человеческую поддержку, честный ответ
об эмоциях, вопрос о возможностях, запись/чтение памяти и серверное создание
напоминания. Проверены файл с SHA/ZIP/ACK, старый точный факт вне выдержки,
продолжение длинного проекта, ошибка/частичный результат, смена темы,
одноразовое подтверждение расхода и Stop. Чужой аккаунт не получил Run.
Это целевые критерии, а не обещание безошибочности любой бесплатной модели.
