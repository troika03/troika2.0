# Компактный контекст Тройки: проверка 14–15 октября 2026

Владелец одобрил сокращение рабочего контекста при сохранении полных
исходных данных. Изменения относятся к product API; Android/WPF в этой
задаче не пересобирались. Оплата и почта остаются выключенными.

## Изменение

В постоянном блоке остаются имя, характер, язык, честность, приватность,
подтверждения и маршрутизация. Подробные инструкции приходят вместе с нужной
capability. Начальный набор модели по-прежнему содержит две схемы. Новый
`troika_context` загружается через существующий plugin API по необходимости;
операторские/default toolsets не расширяются.

Полные SOUL, память, проекты и сообщения сохраняются. SDK получает производную
копию с релевантной памятью, точными выдержками и полными свежими ходами.
При большой завершённой цепочке инструментов хвост сокращается; текущий ход
остаётся целиком. Индекс обозначает неполноту и даёт номера оригиналов.
Полный исходный текст читается постранично с проверкой account/device token.
Создание индекса не вызывает модель. RAM-кеш проверяет владельца и весь
префикс, ограничен размером/TTL и очищается при удалении аккаунта.

Учёт резервирует преобразованный запрос. Корпоративный Free сохраняет правило
prompt + completion, включая cache; BYOK за модель не списывает ресурс подписки.
Платные голосовые операции и коэффициенты моделей не изменялись. Флаг
`product_compact_context_enabled` по умолчанию false; прежний режим сохраняется.

## Ограничения

Сокращённое представление не гарантирует одинаковый ответ любой модели.
Для отсутствующей детали нужно чтение оригинала, которое добавляет шаги.
Если нужен весь материал, его передача остаётся расходом. Multimodal/async
history и отключённый reader передаются без индекса. Текущий длинный ход не
обрезается. Проверки голосового воспроизведения, файлов на устройстве,
разработки и платежей не объявляются новым установленным-client E2E.
