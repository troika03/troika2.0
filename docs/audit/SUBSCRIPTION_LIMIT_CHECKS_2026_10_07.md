# Подписка: дневные лимиты и профиль

Проверка 7 октября 2026 года. Writable checkout `D:\troika-product`, ветка
`codex/product-foundation`. Изменение исправляет существующий дневной счётчик;
не реализует оплату или месячные credits из Word-плана.

## Причина и изменение

Default gateway и production Compose явно отключали quota enforcement.
Счётчик существовал, но cloud run не расходовал его. Теперь ограничения
включены по умолчанию; явный opt-out остаётся для разработки.

Оба входа AI — `/v1/runs` и `/v1/chat/completions` — резервируют запрос до
работы агента. Исчерпание возвращает 429, стабильный код ошибки, текущий
остаток, `resets_at` и `Retry-After`. Два устройства используют один атомарный
остаток. Сбой quota service возвращает 503, а не запускает бесплатную работу.

Клиент показывает тариф, расход, остаток и обновление в местном времени прямо
в профиле. Есть автоматическое обновление после cloud request, при возврате
приложения и раз в минуту; ручное обновление и понятный отказ. При ошибке
устаревшие числа скрываются. Дневной quota отказ отличается от перегрузки
провайдера. Тёмная/светлая темы просмотрены, узкий экран и масштаб текста 1,5
проверены без overflow.

## Ограничения и следующий шаг

Существующие дневные entitlements не изменены: при диагностике Free 1,
Pro 10 000 запросов/сутки. Эти значения не отражают месячную экономику и не
объявляются окончательной тарифной политикой. Месячный cost ledger, budgets
всех внутренних вызовов, антифрод бонусов, checkout/webhooks/cancel/refund
отсутствуют. [Экономика](../TROIKA_SUBSCRIPTION_ECONOMICS.md) — предложение:
Free 300 / Plus 3 000 / Pro 6 000 credits, не применённые новые лимиты.

Profile/limits клиент собран отдельно от незавершённых native/reminder правок;
новый UI ещё не проверен на установленном устройстве. APK release собрана с
текущей конфигурацией подписи проекта; готовность платного подписанного релиза
не подтверждена. Нужен согласованный выпуск клиента и
свежий E2E с исчерпанием, обновлением суток и двумя устройствами.

Локальные артефакты: `work/subscription-fix/release/` — Android release APK
и Windows debug ZIP. Артефакты не включены в Git; перед установкой требуется
объединить новый профиль с актуальными native/reminder изменениями, чтобы
отдельная сборка не откатила их.
