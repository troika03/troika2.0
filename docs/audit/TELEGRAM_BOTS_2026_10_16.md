# Магазин и поддержка Telegram — 16 октября 2026 года

## Результат

В BotFather зарегистрированы [@troika03_shop_bot](https://t.me/troika03_shop_bot)
и [@troika03_support_bot](https://t.me/troika03_support_bot). Через Bot API
проверены оба username, установлены русские имена, описания, список команд,
кнопка меню и разные аватары из фирменного комплекта.

Магазин показывает Free, Plus, Pro, информацию о продукте, загрузку,
личный кабинет и поддержку. Поддержка содержит справку, выбор темы, обращения,
дополнения, ответы оператора и закрытие. Владелец работает через `/admin`
в поддержке; отдельного третьего бота нет.

По уточнению владельца старое меню удаляется при переходе по inline-кнопкам.
Удаление применяется только к сообщению нужного бота в личном чате нажавшего
пользователя. Сообщения клиента и переписка по обращению сохраняются.

Оплата выключена по прямому решению владельца. Счета не выставляются,
`pre_checkout_query` отклоняется. Цены Plus и Pro в Stars пока не утверждены.
Рублёвые цены показаны как ориентиры сервиса, без внешнего checkout в Telegram.
Выдача платного периода и привязка аккаунта для покупки не объявлены готовыми.

## Production

Оба бота работают одним изолированным сервисом `production-telegram-1`.
Единственный manifest: `deploy/production/compose.yaml`, профиль `telegram`.
Новый сервис запущен с `--no-deps`; API, STT и поиск этой задачей не
перезапускались и их данные не менялись. Параллельные обновления API из других
задач не входят в этот аудит.

Runtime закреплён отдельным image tag `troika-production:telegram-runtime-20261016`,
image ID `sha256:b4e528b64f15fef7005d371292faa90fea65a29de49f8bdcd51d0da74e5309ef`.
Код находится в `/srv/troika/releases/telegram-20261016/telegram_commerce`;
каталог подключён read-only. Конфигурация, ключ шифрования и отдельная SQLite
находятся в `/srv/troika/telegram`, вне Git и данных Troika API. Каталог — 0700,
секреты — 0600. Отсутствуют опубликованные порты и доступ к Docker socket.
Процесс работает от UID 1000, с read-only filesystem, без capabilities,
с ограничениями памяти 192 MiB, CPU 0,5 и числа процессов.

Боты не используют LLM, инструменты Hermes или аккаунты продукта. Поддержка
шифрует тексты и очередь Fernet; Telegram ID и технические поля защищены правами
каталога. Секреты, переписка и числовой ID оператора не включены в этот отчёт.

В основном `resource-images.env` добавлены только две переменные сервиса
Telegram; остальные image tags сохранены. Канонический Compose проверен
командой `config --quiet`. До изменения сохранена серверная копия manifest.
Остановка сервиса Telegram не требует удаления его базы или изменения API.

## Общий baseline и предел доказательств

Полный default Python-прогон был начат через штатный runner. Он выявил
ошибки вне пакета ботов: ACP, LSP, provider adapters, hooks и другие upstream
тесты. Прогон остановлен после 132 завершённых файлов; последний опубликованный
счётчик — 3 344 passed, 25 failed. Это частичный прогон, не зелёный общий baseline.
Локальный полный лог остался вне Git. Работающие боты и целевые проверки не
закрывают эти ошибки или все release gates Troika 1.0.

Проверка поддержки выполнена одним реальным аккаунтом владельца, который
играл обе роли. Изоляция разных пользователей и запрет чужого ответа проверены
автоматически; отдельный физический тест со вторым Telegram-аккаунтом не
проводился. Постоянное присутствие оператора и срок ответа не обещаются.
Вложения в поддержку пока не принимаются.
