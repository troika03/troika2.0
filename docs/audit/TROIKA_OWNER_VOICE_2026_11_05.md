# Проверка голоса владельца

5 ноября 2026 года. Владелец запросил регистрацию своего голоса для Android и
Windows и выбрал строгую проверку, даже если она требует более длинной команды.
После замечания о количестве текста экран сокращён; объяснения свёрнуты.

## Поведение

Три согласованных образца регистрируются на каждом устройстве отдельно.
Регистрация не включает фильтр автоматически. Переключатель находится в
«Мой голос». Android принимает «Тройка» вместе с полной командой; Windows
сохраняет существующий push-to-talk. Фоновое пробуждение Windows не добавлено.

Используется Vosk speaker model 0.4: вектор из 128 значений, минимум 400 речевых
кадров, около четырёх секунд речи. Образцы попарно должны иметь cosine similarity
не ниже 0,75. Для команды проверяется медиана трёх сравнений с тем же порогом.
Это выбранная настройка фильтра, а не измеренная точность идентификации.

Android проверяет пробуждение, ручной ввод и каждую последующую реплику до
локального действия, передачи агенту или ответа. Начальная команда сохраняется
после проверки wake, чтобы не терять речь после слова «Тройка». Один общий ASR
Model используется ожиданием и захватом. В обычном режиме остаётся прежний
быстрый локальный wake. Windows проверяет запись до серверного STT.

Недостаточная речь, чужой голос, повреждение профиля или недоступная модель
блокируют защищённый запрос. Текстовый ввод и удаление профиля остаются доступны.
Запоздалые результаты отклоняются после Stop, смены аккаунта, политики или
отмены регистрации. Микрофон передаётся между ожиданием и записью с барьером.

Регистрационные записи не сохраняются и не отправляются. На Android векторы
находятся в noBackupFilesDir с AES-GCM/Keystore и привязкой к исходному аккаунту
и серверу. Windows использует DPAPI CurrentUser и привязку к аккаунту.
Модели поставляются при сборке с проверкой размера и SHA-256; runtime их не
скачивает. Бинарные модели не входят в Git, лицензии сохранены.

## Оставшаяся приёмка

Регистрацию настоящего голоса выполняет сам владелец. Нужны проверки владельца
и другого человека на обоих устройствах, шума, расстояния, Stop, повтора записи,
перезапуска, battery/standby и реальной задержки Android. Запись или имитация
голоса может пройти фильтр; он не заменяет пароль и подтверждения действий.
Установка, unit tests и public-WAV smoke не закрывают эти критерии и общий
release gate. Сервер, модель ответа и естественный TTS этой задачей не менялись.
