# Публикация сайта Тройки в Timeweb — 16 октября 2026 года

Сайт доступен по HTTPS: https://cm444726.tw1.ru/. Технический домен привязан
к существующему сайту `troika`, ID 9427125, аккаунт `cm444726`, сервер
`vh460.timeweb.ru`. HTTP возвращает 302 на HTTPS. Платные услуги не покупались.

## Развёрнутая версия

Страницы и брендовые ресурсы взяты из `troika-site/src`, используется комплект
`brand/troika`. Тексты сохраняют согласованную короткую подачу. `build:timeweb`
собирает отдельный каталог; прежний изменённый `dist` не включён в релиз.
Архив `work/Troika-Timeweb-2026-10-16.zip` содержит исходники размещения,
не содержит runtime-ключей, базы или установщиков.

PHP 8.2.32 с cURL, OpenSSL, mbstring и PDO SQLite обращается напрямую к
`https://api.zhulebino-teahouse.ru`. Существующие аккаунты, ресурс, устройства,
память, экспорт и удаление обслуживает прежний API. Cookie зашифрована
AES-256-GCM и имеет Secure, HttpOnly, SameSite=Lax. Origin обязателен для
изменений; список API фиксирован, внешние перенаправления запрещены.

Обращения и ответы хранятся в SQLite, пользовательские тексты и почта
зашифрованы отдельным ключом. Доступ привязан к SHA-256 home session ID;
чтение поддержки дополнительно проверяет действующий доступ через API.
Папка `troika/private` имеет 0700, ключи и база 0600, находятся вне webroot.
Оператор использует отдельную CLI-команду в авторизованной консоли Timeweb.
Email клиента не даёт административной роли. Ответ проверен на синтетическом
обращении, затем тестовый аккаунт и все его строки удалены.

Перед переносом инструментами Sites проверены `support_tickets` и
`support_replies`: обе таблицы пустые. Исходный Sites остался закрытым для
посторонних, D1/R2 не удалялись. Первоначальный PHP-мост оказался недоступен
из-за Cloudflare 403 при обращениях с Timeweb и заменён прямым адаптером.
Старый служебный файл `private/backend.json` не используется новой версией.

## Ограничения и эксплуатация

Панель показывает 8 дней тестового периода, баланс 0 ₽, Optimo 729 ₽/месяц.
Бесплатный технический домен не означает бессрочный бесплатный хостинг.
Поддержка Timeweb по ранее согласованному тикету №12842651 сообщала о DDoS
и фильтрации, затронувших SSH/FTP и сайты. Новых сообщений ей не отправляли.

Оплата и почта отложены владельцем. Recovery/email verification, реквизиты
продавца и проверка legal, production backup/deletion/restore и подпись
установщиков остаются общими gates. Публичный сайт не закрывает весь релиз 1.0.

Автоматическая проверка 15 октября отклонила удаление временной локальной
копии прежнего служебного ключа. Она остаётся в `work/timeweb-private`,
закрыта ACL текущего пользователя и исключена из Git; в архив публикации
не входит. Удаление другим механизмом не предпринималось.
