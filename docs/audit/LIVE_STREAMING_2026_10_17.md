# Потоковые ответы Тройки — 17 октября 2026 года

## Изменение

В product API текст ранее удерживался до завершения и проверки всего ответа.
Android уже имел очередь озвучки, но не получал ранний текст от этого API.
Теперь `/v1/chat/completions` и `/v1/runs` передают обычные завершённые фразы
во время генерации. Утверждения о выполненных действиях, найденные существующим
словарём completion guard, и текст после них остаются до проверенного результата.
Финал передаётся один раз, без повторения уже отправленного префикса.

`troika_product/streaming.py` использует тот же детерминированный словарь, что
и completion verification. Это ограниченная защита от известных формулировок,
не семантическая проверка произвольного текста. Проверка receipts и штатное
исправление финального ответа сохранены. Незавершённая фраза ограничена 4096
символами, отправленный префикс — 65536; ошибки не выпускают отвергнутый финал.
Code fences удерживаются. Upstream-фильтрация скрытых рассуждений сохранена.

Для строгого social-only запроса, например отдельного «Привет!», reasoning
выключен. Для остальных hosted запросов без операторской настройки effort
по умолчанию `low`; явная настройка effort и выбор личного API сохранены.
Приветствие с просьбой выполнить действие не считается social-only.
Модель `openrouter/free` и production config не заменялись.
