**Исправленные расхождения.** WPF отклонял Go/Rust и `.gitignore`, а ошибку формата называл сетевой. Flutter игнорировал результат изолированных тестов при показе ревью. API мог открыть базу сессий по пути прежнего профиля и вернуть законному запросу `403`. На странице загрузок повреждённая запись одной платформы скрывала вторую, а поздний ответ буфера обмена ломал надпись на кнопке. В локальном просмотре сайта пустой DELETE превращался в запрос с пустым потоком JSON и мешал удалять запись памяти. Чистая сборка WPF также обнаружила неопределённую кисть в панели возможностей. Использована существующая кисть темы. В чистой сборке сайта команда тестов теперь сама собирает Worker.

**Автоматические проверки.** В `tests/troika_product` прошёл 1231 тест, 15 пропущены. Flutter — 344 прошли, 3 пропущены; анализатор выдал 75 замечаний уровня info после исправления экрана ревью. WPF собран, штатный `build.ps1 -Test` прошёл в рабочей копии и в версии для коммита. В чистой копии также прошли 33 проверки API сессий и доступа и тесты экрана ревью Flutter. Сайт прошёл сборку и 12 тестов. TUI прошёл проверку типов, сборку и 854 теста, 8 пропущены. Веб-панель Hermes собралась, ESLint вернул 22 ошибки и 4 предупреждения. Это отдельный компонент от сайта продаж.

**Общий набор Python на Windows.** Штатный runner охватил все 1297 обнаруженных файлов рабочего дерева. После первого прерывания из-за места на C: запуск продолжен группами. С учётом отдельной перепроверки исправленной авторизации 1170 файлов завершились без ошибок, включая 13 файлов только с пропусками, 127 завершились со сбоями. Наибольшие группы сбоев — tools (33), hermes_cli (31), run_agent (14) и gateway (13). Например, тест без поискового провайдера обнаружил установленный DDGS, а один тест Windows обратился к отсутствующему signal.SIGKILL. Причины остальных сбоев требуют отдельного разбора. Все 68 файлов tests/troika_product завершились без ошибок. Интеграционные сценарии с отдельными сервисами исключены из этого набора по умолчанию.
