# Независимый клиент Windows: проверка 8 октября 2026

По запросу владельца создан `troika-desktop`: самостоятельный WPF-клиент
на .NET Framework 4.8, без сборки мобильного Flutter-приложения. Неоновая
сфера, бирюзовые акценты и фиолетовые орбиты дополняют одно компактное окно.
Панели функций встроены в него; компактный режим не создаёт второго окна.

## Проверенный результат

Сборка `build/neon-release` завершилась без ошибок. Все 25 собственных тестов
прошли: SSE/ошибки/разрыв потока, capability gate, approvals, quota, refresh,
безопасный TLS retry, отсутствие повтора неоднозначной транспортной ошибки,
origin guard, размер загрузки, DPAPI/owner folders, checksum/save-before-ACK,
повтор потерянного ACK, безопасные имена, WAV, Stop, ZIP traversal/секреты,
новая папка проекта, реальные Python failure/fix/pass, zero-tests, остановка
процессов и фильтрация контекста для исправления.

WPF-просмотрены размеры 960 × 680, 780 × 540, компактный 480 × 600,
светлая тема и панель «Возможности». Проверка координат основных элементов
управления не обнаружила выхода за границы. Финальная установленная версия
просмотрена через Windows UI; повторный запуск завершился успешно и оставил
один процесс. Снимки с реальными пользовательскими сообщениями не добавлены в Git.

Живой тест временного аккаунта подтвердил регистрацию, subscription/devices,
создание/завершение задачи, поток облачного ответа, историю, создание DOCX,
локальную запись и SHA-256, ACK с исчезновением передачи на сервере, непустой
MP3 от TTS. Тестовый аккаунт удалён. Эта проверка не подтверждает прослушивание
звука и запись физического микрофона.

Позднее расширенный живой тест с login, memory CRUD, project notes, notification
preferences и account export остановился на TLS EOF. Эти дополнительные
сценарии реализованы, но их свежая серверная проверка не завершена.
Проверка через production admin обнаружила 0 оставшихся активных аккаунтов
с выделенным тестовым префиксом. Никакой пользовательский аккаунт не удалялся.
Проверку TLS не обходили; сертификат проверяется стандартным Windows stack.
Неоднозначные сбои отправки изменяющего запроса автоматически не повторяются.

хранит собственную сессию через DPAPI и настройки в `%LOCALAPPDATA%\TroikaDesktop`.

## Оставшиеся ограничения

Нужен установленный E2E микрофон/STT/ответ/TTS/Stop, а также создание,
получение и открытие файла. Напоминания работают при открытом/свёрнутом
клиенте; после полного закрытия фоновая доставка отсутствует. Не реализованы
Windows wake word, live screen/camera, signed installer/automatic updates,
полный offline sync, изменение существующих Office-файлов, произвольные
repository builds, установка зависимостей и phone-to-PC Companion.

Локальные проверки Python/JavaScript запускаются после явного подтверждения
с правами пользователя; Job Object обеспечивает остановку, а не sandbox.
Исходники и отчёт отправляются для исправления только после отдельного
подтверждения. Предварительная сборка не закрывает весь раздел Windows
главного Word-плана и не объявляется публичным релизом.

Мобильный source и backend этой задачей не изменены. Их незавершённые изменения
других сессий не включаются в commit. Повтор полного Python/Flutter baseline
не проводился; собственная сборка и тесты нового клиента выполнены.
