# Архив документации

Материалы здесь сохраняют историю решений и прежние результаты проверок.
Они не являются текущей памятью, планом релиза или инструкциями deployment.
Даты внутри документов относятся к прежним этапам.

- `PROJECT_MEMORY_BEFORE_2026_10_05.md` — прежний журнал памяти, включая устаревшие сведения о runtime.
- `EXECUTION_TRACKER_BEFORE_2026_10_05.md` — прежние отметки выполнения разделов.
- `PRODUCTIZATION_PLAN_BEFORE_2026_10_05.md` — старая параллельная очередь A–E.
- `CAPABILITY_PLAN_BEFORE_2026_10_05.md` — подробные ранние исследования media architecture.
- `TROIKA_*_PLAN.md` — superseded планы монетизации, offline beta, PC, Kali и улучшений.

Относительные ссылки и команды внутри исторических снимков сохранены как были;
они могут быть устаревшими. Для работы использовать [активную документацию](../README.md).
