# Закрытая beta: доступ пользователей и устройств

Этот режим предназначен для закрытой beta до self-service регистрации и billing.
Он заменяет общий API-ключ индивидуальными токенами устройств и не включает
глобальные cron-задачи или удалённое управление телефоном.

## Запуск сервера

В `.env` на сервере включи:

```env
TROIKA_PRODUCT_AUTH_ENABLED=true
TROIKA_PRODUCT_AUTH_DB=/opt/data/troika_access.db
TROIKA_PRODUCT_QUOTAS_ENABLED=false
TROIKA_PRODUCT_ARTIFACT_ROOT=/opt/data/troika_artifacts
```

Запусти gateway и STT proxy из корня репозитория. API server и STT proxy будут
принимать только токены вида `trk_live_…`; `API_SERVER_KEY` больше не является
пользовательским ключом в этом режиме.

При обновлении существующего Docker volume stage2-hook заменит только точный
дефолтный `SOUL.md` upstream Hermes на продуктовую личность Тройки. Если в
volume уже был изменённый пользователем `SOUL.md`, он не перезаписывается:
product mode всё равно использует встроенную личность Тройки для клиентских
сессий.

## Выдача доступа

Для каждого beta-пользователя и его устройства выполни на сервере:

```bash
python -m troika_product --database /opt/data/troika_access.db provision \
  --email user@example.com --device-name "Pixel 9" --platform android \
  --plan beta --daily-request-limit 50
```

Передай значение `token=` пользователю безопасным каналом. Он вводит его в
Android-приложении в «Настройки → API ключ». База хранит только SHA-256 digest
токена, поэтому восстановить его после выдачи нельзя.

Оператор может изменить лимит существующего пользователя без перевыпуска токена:

```bash
python -m troika_product --database /opt/data/troika_access.db set-limit \
  --user-id usr_... --plan pro --daily-request-limit 200
```

## Usage в текущей разработке

По решению владельца продукта пользовательские лимиты пока выключены:
`TROIKA_PRODUCT_QUOTAS_ENABLED=false`. Схема entitlement/usage сохранена и
проверена тестами, но `/v1/runs` и `/v1/chat/completions` сейчас не отклоняют
запросы по дневной квоте и не показывают quota-заголовки. Перед платным запуском
лимиты и биллинг нужно спроектировать отдельно, а не просто включать старый
дневной счётчик.

Технические границы размера HTTP-запроса и одного создаваемого файла остаются:
это защита процесса и диска от аварии, а не тарифное ограничение.

## Audit beta

База сохраняет append-only события без текста запросов, токенов и raw session
IDs: выдача лимита, запуск и остановка run, approval, отказ доступа, исчерпание
лимита. Для диагностики одного пользователя используй:

```bash
python -m troika_product --database /opt/data/troika_access.db audit \
  --user-id usr_... --limit 100
```

`session_digest` и `run_digest` — односторонние ссылки для корреляции, не исходные
значения. Записи — продуктовый журнал beta, но не WORM-хранилище: доступ
операторов к серверной SQLite-базе должен быть ограничен.

## Privacy местоположения

Передача device context в Android выключена по умолчанию. Системное разрешение
на геолокацию само не включает её: пользователь отдельно включает переключатель
в «Настройки → Местоположение». Только тогда приложение отправляет GPS, Wi-Fi и
Bluetooth context. При выключении следующий запрос очищает временный context на
сервере. Product server игнорирует context без явного `granted` consent header.

Точные координаты не отправляются во внешний reverse-geocoding сервис по
умолчанию. `TROIKA_EXTERNAL_GEOCODING_ENABLED=false` оставь выключенным до
отдельного consent flow, privacy policy и оценки провайдера.

## Привязанный Android-телефон

В product mode телефон подключается к `/v1/phone/commands` тем же индивидуальным
`trk_live_…` токеном. Сервер хранит соединение отдельно для каждого device ID:
команда пользователя никогда не маршрутизируется на другой подключённый телефон.

Канал команд выключен по умолчанию. После сохранения адреса сервера и токена
пользователь отдельно включает «Настройки → Управление телефоном → Разрешить
управление телефоном». Выключение переключателя сразу закрывает WebSocket.
Спец. возможности Android нужны дополнительно только для нажатий, свайпов и
ввода текста; status, battery и network работают без них.

Первая beta-версия доступна только из текстового чата приложения, который
использует `/v1/runs`. Она умеет показать status/battery/network и по отдельному
подтверждению открыть приложение или поиск, поставить будильник/таймер, открыть
навигацию, изменить громкость/яркость/фонарик или открыть камеру. Перед каждым
изменением приложение показывает действие и предлагает только «Разрешить один
раз» или отмену. Отсутствие ответа, потеря канала или закрытие UI означают отказ.

Не добавляй в beta SMS, звонки, clipboard, файлы, скриншоты/экран или календарь
без отдельного privacy review, модели доступа и тестов. Они сознательно не
включены в product toolset.

## Личные документы

Product toolset умеет создавать DOCX, PDF и PPTX. Файл сначала собирается в
памяти без доступа модели к путям сервера, затем приложение показывает разовое
подтверждение сохранения. После подтверждения файл получает opaque ID и
появляется в «Файлы Тройки».

- `GET /v1/artifacts` — список файлов только текущего пользователя.
- `GET /v1/artifacts/{id}/download` — проверенное скачивание владельцем.
- `DELETE /v1/artifacts/{id}` — удаление владельцем; приложение отдельно
  подтверждает его диалогом.

Физический путь, storage name и user ID не возвращаются модели или приложению.
При скачивании проверяются размер и SHA-256, а создание/скачивание/удаление
попадают в privacy-safe audit без содержимого документа и имени файла.

Чтобы оставить копию на телефоне, в «Файлы Тройки» нажми значок скачивания
у документа. Android откроет системное окно выбора папки и имени через Storage
Access Framework; широкое разрешение «All files access» для этого не нужно.
До подтверждения выбора файл остаётся только во временном кэше приложения.

## Ограничения beta

- Нет публичной регистрации, платежей, восстановления доступа или push-delivery.
- История чата и location fingerprints изолированы по user/device token.
- Доступ к status, events, approval и stop конкретного run изолирован по
  user/device token.
- Legacy `/v1/responses` временно отключён: его старое хранилище не имеет
  tenant ownership. Клиент beta использует `/v1/runs` или `/v1/chat/completions`.
- Product API использует safe toolset и узкий paired-phone slice. Он не получает
  terminal, файлы сервера, PC control, SMS/звонки/файлы телефона,
  `find_tool` или `run_tool`, даже если локальный оператор включил их в конфиге.
- Глобальные jobs остаются выключенными: адресная доставка ещё не реализована.
  Личные notification preferences и проверка тихих часов доступны через
  [отдельный API](TROIKA_NOTIFICATION_PREFERENCES.md); Android UI и доставка
  пока не подключены.
