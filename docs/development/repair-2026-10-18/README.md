# Исправление Troika: задания сессий

[Главный подробный промпт](MASTER_PROMPT.md) задаёт все области, ограничения,
этапы и приёмку. [Реестр](SESSION_REGISTRY.json) содержит созданные сессии.

Владелец выбрал отдельное полноценное окно проекта на ПК. Дизайн остаётся
единым; короткие подписи и действия на экране, подробности — в раскрытиях.
Android получает самостоятельную полноценную разработку без обязательного ПК.
Переданный ранее план сохранён и включён в общий промпт.

Восемь исполнителей готовят самостоятельные candidate/patch и доказательства.
Координатор интегрирует; независимая приёмка проверяет весь продукт. Общий
checkout и незавершённые изменения других задач не редактируются параллельно.

и [сравнение с Codex/Claude Code](../../audit/CODEX_CLAUDE_DEVELOPMENT_GAP_2026_10_18.md)
различают доказанные дефекты, ограничения и непроверенные сценарии.
