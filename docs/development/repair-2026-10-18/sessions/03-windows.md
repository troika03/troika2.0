## Задачи

1. Развивай самостоятельный WPF; не подменяй его старым Flutter Windows. Прочитай UI guide и VOICE_DEVELOPMENT_WORKSPACE_PROMPT.md. Владелец прямо выбрал отдельное полноценное окно проекта 18 октября. Оно использует общий runtime аккаунта/голоса/работы; дизайн единый с Тройкой, текст краткий, подробности раскрываются по запросу.
2. Воспроизведи и исправь C1–C5: допустимые сервером языки и .gitignore сохраняются; статусы MODEL_REVIEW отражают manifest; исходная рабочая папка сохраняет связь с проектом; продолжение видит текущие ручные изменения; импортированному проекту можно дать своё поручение.
3. Реализуй настоящую рабочую среду: дерево, вкладки редактора, номера строк/подсветка/поиск/несохранённые изменения, разговор и реальная команда, журнал/проверки, рабочий preview. Панели адаптируются и скрываются без потери состояния.
4. Открывай существующую разрешённую папку/repository, не только заново распакованный ZIP. Добавь diff, выбор принятия/отклонения, version conflict/revert, устойчивый путь после restart и отсутствие дублей распаковки. Проверка ссылок/выхода за папку и secrets остаётся.
5. Проверь desktop mic/STT/TTS, phrase queue/barge-in, Ctrl+Alt+T/Esc, компактный режим, tray/явный выход, фоновые проекты и голосовые отчёты без повтора. Только реальные действия и правильный вывод ошибок.
6. Проверь account refresh/DPAPI/BYOK/devices/revoke, memory/tasks/files/subscription/capabilities, потерю сети и смену аккаунта во время операции. Приём проверок с телефона остаётся opt-in с локальным подтверждением.
7. Раздели локальную проверку, фиксированный isolated checker и неподдержанный стек. Рабочий preview не должен открывать произвольные команды/сеть вне согласованной среды. Не выдавай сохранённый HTML за опубликованный сайт.
8. Измени пустые состояния/быстрые действия по целям пользователя; рабочий проект должен быть заметен. Сохрани темы, Golos Text, доступность и действующие установленные данные.

## Приёмка

- Настоящие Go и Python+.gitignore ZIP проходят доставку/извлечение; опасные пути и ссылки отклоняются.
- После ручной правки и restart «Показать результат» возвращает ту же папку; новая функция сохраняет правку и показывает diff.
- WPF checks/build; установленный EXE отдельно проверяет микрофон, звук, hotkey/tray, файл, pause/resume/Stop.
- Обновление не сбрасывает аккаунт, разрешения, файлы и совместимость существующих протоколов.
