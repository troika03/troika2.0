## Задачи

1. Проверь все register/login/logout/access/refresh/revoke/devices/export/delete пути и миграции. Восстановление пароля/verification подготовь с выключенными live флагами; не включай отложенную владельцем почту.
2. Определи понятные связи проекта дел, заметки, задачи, development project, Run и локальной версии. Не делай из записанной задачи автоматическое действие. Предложи совместимую миграцию, сохраняющую существующие ID/ownership.
3. Проверь историю/home session/ротации/исходный архив: смена темы не возобновляет прежний запрос, явное продолжение находит правильный контекст, длинная реплика не теряется. Отдельно общий разговор и project conversations.
4. Проверь memory CRUD, точный контекст, явное запоминание, opt-in automatic memory, изменение/удаление факта, исключение секретов и чувствительных данных. Удаление обязано влиять на caches и новые запросы.
5. Доведи проекты/дела/заметки/reminders/inbox/quiet hours/timezone/opt-in до согласованного поведения. Не считать серверную запись доказательством доставки; повторы, отмена, изменение срока и переход периода должны быть идемпотентны.
6. Реализуй недостающие sync/offline contracts: change IDs/version, idempotency keys, очередь, tombstones и разрешение конфликтов. Два устройства не должны молча перетирать записи или возвращать удалённое.
7. Проверь refresh/revoke во всех native/background путях совместно с клиентами; не создавай третий дублирующий механизм reminders. Подготовь сценарии standby/reboot/expiry и состояние отключённого устройства.
8. Распространи export/delete на новые проектные metadata, настройки расширений и фоновые Run. Локальные исходники не обещай восстановить из серверной истории.

## Приёмка

- Два аккаунта и два устройства: изоляция, refresh/revoke, одновременная правка/удаление, повтор после сетевого сбоя.
- Новая функция проекта связывается с правильной беседой/делом и локальной версией без потери старых записей.
- Напоминание меняется/отменяется без дубля; сервер и реальное устройство отмечаются разными уровнями доказательства.
- Export/delete очищают live данные и отключают новую работу; backup cleanup согласован с 08.
