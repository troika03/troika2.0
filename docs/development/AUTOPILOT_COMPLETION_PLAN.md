# Завершение автопилота разработки

Запрос владельца от 15 октября 2026 года дополняет действующий автопилот Pro.
Существующие подписки, личный API, изоляция аккаунтов и запрет платного fallback
сохраняются. Наличие реализации не заменяет проверку установленного клиента.

## Сохранение и управление

Исходники и запрос хранятся в локальной контрольной копии устройства. Сервер
держит исходники только в RAM; в SQLite сохраняются собственник, идентификатор,
версия, хеш контрольной копии и состояние. После восстановления соединения
клиент возвращает последнюю сохранённую копию. Незавершённый API-вызов не
объявляется завершённым и не восстанавливается по предположению.

Пауза прекращает новые обращения и сохраняет завершённые файлы. Продолжение
проверяет право Pro, устройство, версию, лимиты и подтверждённый дополнительный
бюджет. Уточнение добавляется явно и перепланирует текущую версию без потери
завершённых файлов. Stop остаётся отдельным действием.

Проверки: перезапуск, обрыв передачи, повтор ACK/Resume, повреждённая версия,
чужой аккаунт/устройство, revoke/logout/downgrade, остановка во время модели,
исчерпание бюджета, отсутствие исходников в серверных БД и логах.

## Проверка результата

Отдельный изолированный исполнитель получает только файлы проекта и выбранный
тип проверки. У него нет ключей, пользовательского профиля, доступа к данным
Тройки или внешней сети. Он ограничен временем, памятью, процессами и размером
ответа. Основной API не получает shell и не запускает сгенерированные команды.

Для HTML создаются изображения широкого и узкого окна; для DOCX/PPTX — страницы
доверенного рендера. Бесплатная vision-модель оценивает реальные изображения,
а замечания возвращаются автору для исправления. Отчёт отдельно фиксирует
проверку исходников, визуальную проверку и исполненные тесты. Неподдерживаемый
тип или недоступный исполнитель получает честный статус, а не passed.

Работа с существующим проектом сохраняет все переданные файлы; разбиение
контекста не пропускает исходники при ревью. Произвольные установки зависимостей
не разрешаются автоматически. Поддерживаемые сборки и тесты выполняются только
в изолированной среде либо через прежнее локальное подтверждение пользователя.

## Клиенты и фон

Android получает локальные контрольные копии и явный фоновый сервис с системным
уведомлением. Он сохраняет результаты и сообщает голосом, когда разговор
свободен. Смена аккаунта, выключение функции и Stop закрывают старую работу.
Принудительная остановка приложения пользователем остаётся ограничением Android.
ПК сохраняет копии под защитой текущего пользователя; закрытие окна может
оставлять наблюдение в области уведомлений, с отдельным действием выхода.

Текущая реализация включена на сервере 17 октября; Android/WPF установлены
без сброса данных. SDK точного EXE прошёл сохранение, паузу/продолжение,
скачивание и очередь. На Android подтверждены оба bridges, пауза/продолжение
и native ZIP в фоне. После раннего зависания integration harness обычная
release APK 18 октября прошла запуск из UI, финальный native отчёт с проверенным
идентификатором и отсутствие повторной озвучки при открытии приложения.
Владелец услышал отчёт. OEM standby/reboot и физический звук WPF остаются
отдельными проверками. Реальные модели собрали Python-примеры с тестами и PPTX
с прошедшей визуальной проверкой. Сайт из модельной контрольной копии прошёл 16 Node-тестов и visual review
при двух ширинах после исправления parser/repair. Public HTTPS E2E также прошёл.
Финальная fixture сайта имела диагностический потолок 1 000 000; выполнение
всего сайта за один продуктовый бюджет 250 000 этим не подтверждено. Доказательства: [аудит завершения](../audit/AUTOPILOT_COMPLETION_2026_10_16.md).

[готовый промпт](VOICE_DEVELOPMENT_WORKSPACE_PROMPT.md). Текущая работа не
объявляет файловый редактор и новое окно уже реализованными.
