# Тройка Offline Beta: план быстрого выхода к пользователям

**Дата решения:** 2026-09-20
**Цель:** дать обычному пользователю установщик с простой регистрацией, после
которой локальные команды работают без API-ключа и ручного запуска сервера.
**Первый рынок:** русскоязычные пользователи Windows 10/11 и Android 12+.

## 1. Решение

Первый публичный продукт — не облачный AI-агент. Первый продукт — бесплатный
локальный голосовой пульт для компьютера и телефона.

Пользователь должен:

1. скачать приложение;
2. установить его обычным мастером;
3. зарегистрироваться или войти;
4. разрешить микрофон;
5. нажать кнопку и произнести команду;
6. получить локальное действие без оплаты и вызова облачной модели.

Под «без AI» в бесплатном тарифе понимается отсутствие облачной генеративной
модели. Локальное распознавание речи использует небольшую ML-модель, но запись
не покидает устройство и не создаёт расходов владельцу продукта.

## 2. Что выпускаем

### 2.1. Тройка для Windows

- один установщик `Troika-Setup-x64.exe`;
- регистрация и вход в приложении;
- приложение в системном трее и обычное окно;
- текстовая строка команды и push-to-talk;
- локальное распознавание русских команд;
- локальный детерминированный роутер намерений;
- локальное выполнение разрешённых Windows-действий;
- системный или локальный голос ответа;
- журнал последних действий только на устройстве;
- удаление журнала одной кнопкой;
- работа без Python, Flutter SDK, терминала и фонового cloud gateway.

### 2.2. Тройка для Android

- APK для закрытого теста; затем Google Play closed testing;
- тот же аккаунт и понятный вход;
- локальные команды без подключения к product API;
- push-to-talk по умолчанию;
- системное on-device распознавание речи на Android 12+;
- fallback на загружаемый русский Vosk-пакет, если системного распознавания нет;
- встроенный Android TTS;
- разрешения запрашиваются отдельно для каждой группы функций;
- банковские, OTP, password и permission-экраны не автоматизируются.

### 2.3. Режим связи телефона и ПК

Связь между устройствами не нужна для первого полезного запуска. Каждое
приложение самостоятельно исполняет локальные команды.

После стабилизации двух приложений добавляется локальное pairing в одной сети:

1. ПК показывает QR с одноразовым ключом;
2. телефон сканирует QR;
3. устройства устанавливают исходящее зашифрованное соединение внутри LAN;
4. команды подписываются ключом пары;
5. интернет и аккаунт не требуются;
6. удаление пары отзывает ключ на обоих устройствах.

Нельзя открывать публичный входящий порт или использовать общий пароль.

## 3. Бесплатные локальные команды

Количество фраз не является продуктовой метрикой. Одна функция может иметь
десятки синонимов. Метрика — доля успешно завершённых намерений.

### 3.1. Windows: обязательный набор beta

| Группа | Действия |
|---|---|
| Приложения | Открыть установленное приложение, закрыть активное окно, переключить окно, показать рабочий стол, открыть диспетчер задач и настройки. |
| Система | Громче, тише, mute, заблокировать ПК, сон, выключение и перезагрузка после подтверждения. |
| Экран | Ярче, темнее, заданный процент, сделать локальный screenshot. |
| Файлы | Открыть Рабочий стол, Загрузки, Документы, Изображения; найти файл по имени; открыть найденный файл. |
| Медиа | Play/pause, следующий и предыдущий трек, регулировка громкости. |
| Браузер | Открыть сайт, выполнить поисковый запрос, открыть почту или карты. |
| Буфер | Прочитать, очистить или записать текст после видимого подтверждения. |
| Сервис | Время, дата, заряд ноутбука, сеть, список доступных команд. |
| Сценарии | «Начало работы», «Режим фокуса», «Кино», «Ухожу» как локальные редактируемые последовательности. |

Произвольный PowerShell, `cmd`, terminal и выполнение текста как команды в Free
Offline не допускаются.

### 3.2. Android: обязательный набор beta

| Группа | Действия |
|---|---|
| Приложения | Открыть приложение по установленному имени или алиасу. |
| Связь | Открыть dialer с номером; открыть экран SMS. Отправка без подтверждения запрещена. |
| Время | Поставить будильник, таймер, открыть календарь. |
| Навигация | Построить маршрут и открыть карты. |
| Поиск | Найти запрос в выбранном браузере. |
| Устройство | Громкость, яркость, фонарик, Wi-Fi/Bluetooth settings, камера. |
| Навигация UI | Назад, домой, последние приложения. Accessibility включается отдельно. |
| Сервис | Время, дата, заряд, тип сети, список команд. |

Файлы, clipboard, календарные изменения, звонок, SMS, taps, swipes и ввод текста
в другие приложения требуют отдельного разрешения или подтверждения. Платёжные
и секретные экраны блокируются всегда.

## 4. Локальный движок команд

### 4.1. Поток выполнения

```text
микрофон или текст
        |
локальное STT
        |
нормализация русского текста
        |
детерминированный intent router
        |
валидация параметров и local policy
        |
подтверждение, если действие опасное
        |
Windows/Android executor
        |
локальный текстовый и голосовой результат
```

Генеративная модель в этом потоке отсутствует. Intent router состоит из
проверяемых шаблонов, словарей приложений, синонимов, чисел, времени и единиц.

### 4.2. Общий контракт команды

```json
{
  "intent": "system.volume.set",
  "arguments": {"percent": 40},
  "risk": "safe",
  "source": "voice",
  "confidence": 0.97
}
```

Executor принимает только известный `intent`. Текст пользователя никогда не
становится shell-командой.

### 4.3. Риски действий

| Уровень | Пример | Поведение |
|---|---|---|
| `safe` | открыть калькулятор, громкость | выполнить сразу |
| `confirm` | закрыть окно, очистить clipboard | показать точное действие |
| `dangerous` | выключить ПК, удалить файл, отправить сообщение | отдельное подтверждение непосредственно перед действием |
| `blocked` | пароль, OTP, платёж, системное разрешение | не выполнять |

## 5. Голос без сложной настройки

### 5.1. Бесплатный локальный режим

**Windows beta:** Vosk с русской моделью около 45 MB и ограниченной грамматикой
команд. Vosk работает offline и поддерживает Android/Windows; небольшой русский
пакет подходит для первого command-only режима. Пользователь не выбирает модель.

**Android beta:** сначала системный `createOnDeviceSpeechRecognizer`, если он
доступен. Android предоставляет проверку доступности on-device recognition.
Если язык не установлен, приложение открывает системную установку русского
языкового пакета. Если on-device service отсутствует, приложение предлагает
скачать встроенный Vosk-пакет один раз.

**TTS:** Android TTS и Windows SAPI являются первыми defaults. Piper с русским
голосом — дополнительный локальный пакет, а не обязательная часть установщика.

### 5.2. UX голоса

- большая кнопка «Говорить»;
- текст распознаётся и показывается до действия;
- безопасные команды выполняются сразу;
- опасные команды требуют нажатия «Подтвердить»;
- после ошибки доступна кнопка «Исправить текст»;
- текстовый ввод работает всегда;
- wake word выключен по умолчанию;
- wake word включается отдельным переключателем с объяснением батареи и
  постоянного микрофона;
- аудиозаписи не сохраняются.

### 5.3. Облачный голос позже

Для платных тарифов cloud STT включается автоматически только при согласии.
Основной кандидат — Whisper Large V3 Turbo через Groq: ориентир $0.04 за час
аудио. Более точный fallback — Whisper Large V3 по $0.111 за час. Локальный TTS
остаётся default, поэтому голосовой ответ не создаёт постоянных cloud-расходов.

Premium TTS продаётся как отдельная опция. Например, Deepgram Aura-1 стоит
$0.015 за 1 000 символов, Aura-2 — $0.030 за 1 000 символов. Цена и provider
должны быть конфигурацией, а не обещанием конкретного бренда навсегда.

## 6. Установка и сайт

### 6.1. Windows

Пользователь скачивает один подписанный installer. Installer:

1. проверяет Windows 10/11 x64;
2. устанавливает приложение в пользовательский профиль без admin, если это
   возможно;
3. включает ярлык и uninstall;
4. предлагает автозапуск, но не включает его скрытно;
5. ставит локальный command model;
6. запускает onboarding;
7. не просит URL, port, token или API key.

Перед публичной beta обязательны code signing, SHA-256, номер версии, changelog
и проверка чистой установки на отдельной машине.

### 6.2. Android

Для первых 20 пользователей допустим APK с сайта и SHA-256. Для более широкой
beta использовать Google Play closed testing, чтобы убрать сложность «неизвестных
источников» и дать штатные обновления.

### 6.3. Статический сайт

Первому сайту не нужен backend. Его можно разместить на статическом hosting.
На главной нужны:

- одно обещание: «Управляйте телефоном и ПК голосом — бесплатно и локально»;
- две кнопки: Windows и Android;
- 20 реальных примеров команд;
- видео длительностью 45–60 секунд;
- блок «Что работает без интернета»;
- разрешения и безопасность простым языком;
- версия, дата, размер, SHA-256 и changelog;
- форма обратной связи без обязательной регистрации;
- privacy policy и условия beta.

## 7. Тарифы после offline beta

### 7.1. Простая линейка

| Тариф | Цена | Что получает пользователь |
|---|---:|---|
| Free Local | 0 ₽ | Регистрация, неограниченные локальные команды, локальные STT/TTS, текстовый ввод и сценарии без cloud AI. |
| BYOK | 199 ₽/месяц или 1 990 ₽/год | Локальный agent runtime, ключ пользователя, документы и расширенные workflows. Расход provider оплачивает пользователь. |
| Personal AI | 490 ₽/месяц | 1 000 cloud credits, память, задачи, документы, cloud STT fallback и синхронизация. |
| Pro Agent | 990 ₽/месяц | 3 500 cloud credits, больше agent-задач, vision snapshot, приоритетные очереди и несколько устройств. |
| Agent Max | 1 990 ₽/месяц | 8 000 cloud credits, длительные исследования, больше документов и ранний PC Companion. |

Free Local должен оставаться полезным. Нельзя превращать его в короткую демо.

### 7.2. Credits вместо ложного числа запросов

Один «запрос» может стоить в сотни раз больше другого. Поэтому сайт показывает
понятные примеры, а backend считает реальную себестоимость.

Стартовая шкала:

| Операция | Credits |
|---|---:|
| Короткий ответ без tools | 1 |
| Длинный ответ или анализ файла | 3–8 |
| Одна минута cloud STT | 1 |
| Vision snapshot | 10 |
| Стандартная agent-задача | 25–60 |
| Web research | 100–250 |
| Большой документ или многошаговая работа | 150–400 |

Перед началом операции дороже 100 credits приложение показывает оценку. При
непредвиденном росте agent loop останавливается на жёстком лимите и предлагает
продолжить. Скрытого перерасхода нет.

### 7.3. Расчёт себестоимости

Плановая формула одной задачи:

```text
model_input + model_output + reasoning + tool_calls + search + STT + TTS
+ storage + payment fee + infrastructure + 30% reserve
```

Для расчёта 2026-09-20 используется консервативный курс 100 ₽ за $1.

Примеры по опубликованным ценам:

- дешёвый ответ на GPT-5.6 Luna при 10 000 input и 1 000 output tokens:
  около $0.0016, или 0.16 ₽, до резерва;
- стандартная agent-задача на более сильной модели с несколькими циклами:
  плановый диапазон 3–15 ₽;
- deep research с поиском и длинным контекстом:
  плановый диапазон 20–80 ₽;
- Groq Whisper Turbo: около 4 ₽ за час распознанной речи;
- один web search по цене $10 за 1 000 calls: около 1 ₽ до model tokens.

Каждый тариф получает внутренний месячный cost cap:

| Тариф | Цена | Максимальный provider budget | Остаток на инфраструктуру, комиссии, поддержку и маржу |
|---|---:|---:|---:|
| Personal AI | 490 ₽ | 100 ₽ | 390 ₽ |
| Pro Agent | 990 ₽ | 350 ₽ | 640 ₽ |
| Agent Max | 1 990 ₽ | 800 ₽ | 1 190 ₽ |

Credits калибруются так, чтобы полный расход лимита не превышал provider budget.
Раз в неделю сравниваются estimated и actual cost. До накопления реальных данных
лимиты нельзя рекламировать как безлимитные.

## 8. Маршрутизация моделей

Пользователь не выбирает модель в обычном тарифе.

| Задача | Маршрут |
|---|---|
| Простая классификация и короткий ответ | дешёвая модель уровня GPT-5.6 Luna или эквивалент |
| Обычный tool use | дешёвая модель; один retry более сильной моделью |
| Многошаговый agent | Gemini Flash/Terra-класс с жёстким iteration budget |
| Сложный документ и исследование | сильная модель только после оценки credits |
| Голосовая команда | локальный intent router; LLM не вызывается |

BYOK хранит ключ только в системном credential store устройства. Ключ не входит
в логи, экспорт, telemetry или crash report.

## 9. План выпуска работающей beta

### Этап 0. Заморозка продукта — 1 рабочий день

- создать отдельный `offline-free` capability set;
- убрать cloud/chat элементы из первого offline onboarding;
- зафиксировать команды и риски;
- подготовить 100 эталонных русских фраз для теста;
- не добавлять новые agent/vision функции до beta.

**Выход:** точный scope и автоматические parser tests.

### Этап 1. Windows Offline — 3–5 рабочих дней

- вынести детерминированный parser из LLM tools;
- расширить безопасный Windows executor;
- добавить текстовый offline command mode в Flutter Windows;
- добавить push-to-talk и Vosk;
- добавить SAPI TTS;
- добавить локальные confirmations;
- собрать self-contained release bundle.

**Выход:** новый пользователь выполняет 30 основных команд без сети.

### Этап 2. Android Offline — 3–5 рабочих дней

- использовать существующий `PhoneCommands` без вызова Hermes API;
- добавить `SpeechRecognizer.createOnDeviceSpeechRecognizer`;
- добавить Vosk fallback;
- разделить onboarding Local и AI;
- проверить разрешения и sensitive-screen policy;
- собрать release APK.

**Выход:** новый пользователь выполняет 20 основных команд в airplane mode.

### Этап 3. Доставка — 2–3 рабочих дня

- Windows installer и uninstall;
- Android closed-test package;
- статический лендинг и downloads manifest;
- версия, SHA-256, changelog, privacy и feedback;
- update check через подписанный статический manifest;
- тест чистой установки.

**Выход:** пользователь скачивает приложение с сайта и начинает работу без
инструкции разработчика.

### Этап 4. Закрытая beta — 7–14 календарных дней

- 20 пользователей: 10 Windows, 10 Android или пользователи обоих устройств;
- первая неделя без платных тарифов;
- ручной экспорт диагностического пакета только по согласию;
- интервью после первого и седьмого дня;
- исправления только по crash, onboarding и command success.

**Выход:** не менее 60% тестеров используют приложение повторно на седьмой день.

### Этап 5. BYOK — после стабильной offline beta

- экран выбора provider с одним рекомендуемым вариантом;
- вставка API key в системное защищённое хранилище;
- проверка ключа одной кнопкой;
- готовые presets моделей;
- estimate spend и локальный monthly cap;
- удаление ключа одной кнопкой.

### Этап 6. Managed AI и billing

- аккаунты, entitlement, credits и usage ledger;
- test billing;
- Personal AI для небольшой группы;
- cost alerts и global kill switch;
- публичная продажа только после проверки удаления данных и восстановления.

## 10. Beta gates

Релиз не отдаётся пользователям, пока не выполнено всё:

- чистая Windows-машина запускает приложение без Python и ручных команд;
- Android не требует адрес сервера или token для Local mode;
- airplane-mode suite проходит;
- 100 parser-фраз дают не менее 95% правильного intent;
- 30 Windows и 20 Android сценариев проходят не менее чем на 90%;
- опасное действие невозможно выполнить без подтверждения;
- неизвестная фраза не превращается в shell-команду;
- аудио не сохраняется и не отправляется в сеть в Local mode;
- uninstall удаляет приложение; локальные данные можно удалить отдельно;
- installer и APK имеют версию, hash и changelog;
- privacy page честно разделяет Local, BYOK и Managed AI.

## 11. Что не делать до первой beta

- не строить live screen/camera;
- не строить полноценный cloud account system;
- не добавлять 3D-аватар;
- не обещать сотни команд до измерения качества;
- не включать постоянный wake word по умолчанию;
- не давать произвольный terminal;
- не делать сложную тарифную матрицу;
- не требовать повторный вход для каждой локальной команды; после регистрации
  хранить сессию безопасно и давать offline grace period;
- не собирать telemetry без отдельного согласия.

## 12. Метрики решения о запуске AI-тарифов

- activation: первая успешная команда менее чем за 3 минуты;
- command success: не менее 90%;
- crash-free sessions: не менее 99%;
- day-7 retained testers: не менее 60%;
- не менее 30% активных тестеров пробуют пять разных намерений;
- не менее 20% тестеров просят свободный AI-запрос, которого нет в Local mode;
- среднее время исправления нераспознанной команды менее 10 секунд;
- ни одного неподтверждённого опасного действия.

Если пользователи не возвращаются к локальным командам, добавление дорогого AI
не исправит core loop. Сначала исправляется установка, голос и полезность.
