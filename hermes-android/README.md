# Тройка — Android-приложение

Голосовой и текстовый клиент Тройки. Сказал «**тройка**» → она ответила голосом. Или напиши в чат — одна общая лента.

## Как работает

```
Телефон (APK)
  ├─ Слушает в фоне → услышал «тройка»
  ├─ Записывает вопрос
  ├─ Отправляет аудио на распознавание речи → текст
  ├─ Текст → сервер Тройки (gateway)
  ├─ Показывает поток мыслей и вызовы инструментов в реальном времени
  └─ Произносит ответ (русский голос)
```

## Что есть в приложении

- **Единый чат** — голос и текст вперемешку, как в мессенджере. Картинки, файлы, кликабельные ссылки.
- **Поток мыслей** — под ответом видно, как Тройка размышляет и какие инструменты вызывает. Английские рассуждения переводятся на русский офлайн (ML Kit).
- **Файлы** — браузер документов, которые создаёт Тройка (бизнес-разборы, исследования). Тап → открыть в Word / Google Документах.
- **История** — все прошлые сессии и диалоги.
- **Настройки** — адрес сервера, ключ, голос, wake-word.
- **Фоновый режим** — слушает wake-word даже со свёрнутым приложением.

## Настройка

1. Открой приложение → ⚙️ **Настройки**.
2. Укажи **адрес сервера** (где запущен gateway, например `http://89.208.105.187:8642`).
3. **Проверить соединение** → должно быть ✅.
4. Выдай разрешения: микрофон, спец-возможности, overlay, отключение оптимизации батареи (для фонового wake-word).

## Сборка

```bash
flutter pub get
flutter build apk --release
flutter install        # установка по USB
```

Версии тулчейна и нюансы сборки — в комментариях [`android/app/build.gradle`](android/app/build.gradle) и [`android/gradle.properties`](android/gradle.properties).

## Структура

| Путь | Что внутри |
|---|---|
| `lib/screens/` | Экраны: чат, файлы, история, настройки, онбординг |
| `lib/services/` | Сервисы: API, голос, распознавание, TTS, перевод мыслей, файлы |
| `lib/config/` | Конфигурация подключения к серверу |
| `android/app/src/main/kotlin/` | Нативный слой: wake-word, фоновый сервис, TTS-плеер |
